# 1·2화 윤수 발화 포인트·문장 적합성 검토

**결론:** 1화 원본 “He is moving!”와 2화 원본 “Hello, little Pinocchio!”는 유지가 적절하다. 2화 첫 신규 목표 “Open, close!”는 두 단어이므로 “Open your hand!”로 바꾸고 첫 반응도 손 펴기로 맞추는 수정이 필요하다. 나머지 다수 표현은 문법보다 지시 대상·시범·행동 순서를 명확히 하는 것이 핵심이다.

검토 범위는 **1화 원본 참여 1개 + 선택 UI 5개 + 2화 참여 10개 = 16포인트**다. 기본 음성 모델 작업은 **I01 1개 + S02 10개 = 11개**이며 선택 UI를 전부 필수 발화로 세지 않는다. 기존 완료본과 원본 대사를 수정하거나 새 음성을 합성하지 않았다.

윤수의 실제 나이·영어 이해도·현재 발화 수준은 제공되지 않았다. 피노키오의 8세 음색 설정을 윤수의 나이로 간주하지 않았다. 아래는 특정 나이의 발달 평가가 아니라, 영어 입문자를 돕는 이야기·상호작용 설계 판단이다.

## 판단 기준

세 단어 조건은 프로젝트의 형식 기준이다. 세 단어라도 긴 이름, 낯선 소리, 추상적 뜻, 대명사나 방향의 지시 대상에 따라 부담이 달라진다. 짧은 구호는 완전한 문장이 아니어도 상황에 맞으면 자연스러울 수 있다. “One small step!”를 문장 조각이라는 이유로 오류 처리하지 않았다.

British Council은 아이가 말할 준비가 되기 전에 여러 번 듣게 하고, 그림·사물·행동으로 의미를 연결하는 활동을 권한다.[1] 자연스러운 문장 억양을 유지한 느린 말, 뜻에 맞는 강조와 표정·몸짓, 응답할 여유도 제시한다.[2] 아직 말하지 않는 아이에게 반복 발화를 강요하지 않고 짧은 통째 표현과 바른 재진술을 제공하라는 안내도 있다.[3] 이를 이 프로젝트의 첫 예시·뜻 보조·부담 없는 응답 설계에 적용했다. 특정 문구나 타이머의 교육 효과가 입증됐다는 뜻은 아니다.

## 포인트별 검토

### S01 · X01 — Tap Pinocchio.

**판정: TOUCH_ONLY** · 뜻: 피노키오를 톡 눌러 봐.

**현재 역할:** TIMELINE required=false인 선택 UI 안내. 필수 학습 발화가 아님.

**상대와 대상:** 앱이 윤수/보호자에게 화면의 피노키오를 누르도록 안내. 피노키오는 아직 살아나기 전.

**화면·문구 적합성:** 방금 제페토가 이름을 붙인 인형을 시각적으로 짚는 활동. 이름과 대상 연결에는 맞음. Tap은 터치 행동을 요청하므로 음성을 요구하면 입력 방식과 문구가 달라짐.

**언어 부담:** 두 단어지만 Pinocchio라는 긴 이름이 포함됨. 단어 수만으로 쉬운 발화라고 볼 수 없음. 이 UI는 세 단어 발화 규칙의 대상에서 제외.

**입력 전후 동작:** 터치는 외부 UI 선택 표시만 바꾼다. 눈·팔다리·몸통을 깨우는 반응을 먼저 재생하지 않는다.

**윤수 지원:** 손가락 아이콘·짧은 한국어 안내·보호자 터치. 발화를 요청하거나 발음 성공을 기다리지 않음.

**최소 권고:** 현재 영어 UI를 유지할 수 있으나 TOUCH_ONLY와 자동 진행을 명시. 말하기 과제 수에 합산하지 않는다.

**근거:** `downloads/s01-complete/TIMELINE.json events[X01], after=S01-U006, time=25.5, seconds=3, required=false`; `downloads/s01-complete/SCREENING_KO.md 음성·참여`

### S01 · X02 — Hello, Blue Fairy!

**판정: OPTIONAL** · 뜻: 안녕, 파란 요정님!

**현재 역할:** required=false인 선택 인사 연습. 원본 이야기의 필수 사건을 여는 발화가 아님.

**상대와 대상:** 윤수가 화면에 들어온 파란 요정에게 인사. 파란 요정 자신의 본편 대사와 구분.

**화면·문구 적합성:** 요정의 등장과 이름/인사를 연결하므로 상황에는 적절함. 인사로 자연스럽고 문법 문제 없음. 본편 요정 대사 Good evening, Geppetto.와 학습자의 인사가 다른 대화 상대를 가진다는 점을 UI로 분리.

**언어 부담:** 세 단어지만 Blue Fairy가 처음 듣는 호칭이고 Fairy의 소리가 낯설 수 있음. 정확한 이름을 모두 말해야 성공하는 과제로 만들지 않음.

**입력 전후 동작:** 3초 자동 진행은 선택 카드의 유지시간이며 영어를 3초 안에 정확히 말해야 한다는 제한이 아님. 다음 본편 음성과 선택 모델이 겹치지 않는지는 별도 플레이어 확인 필요.

**윤수 지원:** Hello만 말하기, 손 흔들기, 보호자 터치, 그냥 보기 모두 허용. 모델을 추가한다면 전체 문장을 먼저 자연스럽게 들려주고 재청취 때 Hello / Blue Fairy로 뜻을 나눔.

**최소 권고:** 선택으로 유지. 피노키오가 윤수에게 답하거나 윤수 이름을 인지하는 새 본편 대사는 추가하지 않는다.

**근거:** `downloads/s01-complete/TIMELINE.json events[X02], after=S01-U008, time=35.1666666667, required=false`; `docs/series_v2/sources/01_STORY_MASTER_V1_1.md 장면1 요정 등장`

### S01 · X03 — Touch the magic light.

**판정: TOUCH_ONLY** · 뜻: 마법빛을 톡 눌러 봐.

**현재 역할:** required=false인 선택 터치 UI.

**상대와 대상:** 윤수/보호자가 화면의 빛을 누르는 동작. 요정의 마법과 아이의 UI 입력을 분리.

**화면·문구 적합성:** 빛이 이미 나타난 화면에서 대상 찾기는 가능. 마법의 시작 원인을 다시 만드는 참여로 쓰면 기존 사건 순서와 어긋남. Touch라는 요청에 터치로 반응하는 것은 적절. 네 단어라는 사실은 현재의 선택 터치 안내를 세 단어 학습 목표 위반으로 만들지 않음.

**언어 부담:** magic이라는 새 단어·추상적 대상과 touch를 한꺼번에 말하게 하기보다 보이는 빛을 짚는 수용 활동에 적합.

**입력 전후 동작:** 선택 UI는 비서사적 하이라이트만. I01 전에는 손가락의 미세 움직임을 넘어 눈뜨기·몸통 기립을 재생하지 않음.

**윤수 지원:** 빛 테두리·손가락 아이콘·짧은 한국어 보조. 발화를 기다리지 않음.

**최소 권고:** TOUCH_ONLY로 유지하고 음성 작업표에서는 기본 발화 모델 수에 넣지 않는다.

**근거:** `downloads/s01-complete/TIMELINE.json events[X03], after=S01-U013, time=51.75, required=false`; `downloads/s01-complete/SCREENING_KO.md C04 마법은 선택 참여 전에 진행`

### S01 · I01 — He is moving!

**판정: KEEP** · 뜻: 움직이고 있어!

**현재 역할:** 원본 정본 발화 목표. 이야기 진행 관문이지만 정확한 영어 발화가 필수 통과조건은 아님.

**상대와 대상:** 윤수가 제페토의 What is happening?에 답하며 피노키오를 he로 가리킴.

**화면·문구 적합성:** 입력 전 손가락만 조금 움직이고 피노키오 전체가 보이는 맥락이면 진행형 관찰과 화면이 맞음. 질문에 맞는 관찰 문장이고 세 단어. Wake up! 같은 명령으로 바꾸면 관찰을 마법 명령으로 바꾸므로 원문 유지가 적절.

**언어 부담:** he의 지시 대상과 moving의 뜻을 먼저 보여줘야 함. 문법 용어 설명 없이 움직이는 손가락과 전체 인물을 함께 짚음.

**입력 전후 동작:** U016 음성 종료 후 본편 정지 → 외부 모델 1회(마이크 OFF) → 모델 종료 후 입력 → 눈/고개/팔/기립 반응. 모델 자체가 VAD에 잡히면 안 됨.

**윤수 지원:** 자연스러운 He is moving! 전체 예시를 기본으로 들려줌. 재청취 때 He is / moving의 뜻 덩어리만 보조. moving, 짧은 소리, 몸짓+보호자 진행도 학습 참여로 인정; 시스템은 단어 점수화를 하지 않음.

**최소 권고:** 목표는 유지. 초회 모델 예시와 마이크 경계가 구현돼 있는지 확인하고, 없으면 별도 외부 모델 경로를 추가한다. UI의 3초 수치와 필수 입력 대기시간을 혼동하지 않는다.

**근거:** `downloads/s01-complete/TIMELINE.json events[I01], after=S01-U016, time=63.25, required=true`; `downloads/s01-complete/TIMELINE.json cues[S01-U016].end=63.1516666667`; `docs/series_v2/sources/01_STEP2_PRODUCTION_STORYBOARD_SPEC.md I01`

### S01 · X04 — Hello, my friend!

**판정: TOUCH_ONLY** · 뜻: 안녕, 내 친구!

**현재 역할:** required=false인 선택 인사 카드. 원본 S01의 필수 대사·이벤트가 아님.

**상대와 대상:** 깨어난 피노키오에게 윤수가 인사하는 것으로 읽히는 UI.

**화면·문구 적합성:** 기쁨을 표현하기에는 맞지만 S02의 첫 친구 발견·수줍음·첫 인사 이전에 같은 관계를 선언함. 문장 자체는 자연스럽고 세 단어. 문제는 문법보다 회차별 첫 만남 역할의 중복.

**언어 부담:** Hello는 친숙해도 my friend가 관계를 이미 확정하는 의미. S02 첫 만남을 살리려면 반복 인사를 기본 학습 목표로 삼지 않는 편이 깔끔함.

**입력 전후 동작:** 이미 생명을 얻은 결과를 외부 UI로 축하할 뿐, 피노키오의 윤수 인지·손 흔들기·관객 인사·이름 부르기를 새로 추가하지 않음.

**최소 권고:** 첫 인사 발화는 S02 I02에 남기고 X04는 반짝이·축하 터치 같은 비언어 선택 활동으로 전환 권고. 기존 Hello를 유지하면 명시적으로 본편 밖 연습이며 등장인물 응답 없는 것으로 제한.

### S01 · X05 — Tell the truth!

**판정: OPTIONAL** · 뜻: 사실대로 말해!

**현재 역할:** required=false인 선택 카드. 요정의 가치 안내 뒤 제시되는 외부 표현.

**상대와 대상:** 윤수가 피노키오에게 건네는 당부로 해석 가능. 아이 자신의 잘못을 검사하는 말이 아님.

**화면·문구 적합성:** 원본 요정이 truth의 중요성을 말하지만 아직 거짓말/고백의 구체적 대비 사건은 없음. 문장 자체는 자연스럽고 세 단어. 눈에 보이는 단일 동작을 시키는 다른 포인트와 달리 추상적 의미를 요구함.

**언어 부담:** truth라는 개념과 말소리가 동시에 새로울 수 있음. 세 단어라는 이유로 I01과 같은 난이도라고 판단하지 않음. 윤수의 실제 수준은 미확인.

**입력 전후 동작:** 이 단계에서 정직함의 정답·거짓말 여부를 채점하지 않음. 새로운 변신·코 변화·벌을 연결하지 않음.

**윤수 지원:** 초회에는 듣기·끄덕임·그냥 보기로 충분. 필요한 경우 보호자가 한 번 짧게 뜻을 돕고, 후반 거짓말/고백 사건에서 같은 표현의 뜻을 다시 확인.

**최소 권고:** 필수 발화로 승격하지 않고 선택 듣기/따라말하기로 유지. 강한 훈계조 대신 다정한 당부로 연기. 본편 원본 요정 문구는 보존.

## 공통 입력·음성 모델 계약

1. 뜻을 보여주는 화면·시범 뒤 본편 질문을 끝낸다. 질문이나 모델이 재생 중일 때 마이크로 답을 받지 않는다.
2. 본편 시계를 멈추고 같은 캐릭터의 외부 모델을 한 번 자연스럽게 들려준다. 설명·감정 태그는 음성으로 읽지 않는다.
3. 모델 종료 후 윤수의 응답을 기다린다. 정확한 단어·발음 점수·문장 완성을 통과 조건으로 삼지 않는다. 3초 자동 카드와 필수 입력 대기는 구분한다.
4. 한 단어·이름 일부·짧은 음성 시도도 참여로 받아들인다. 이는 STT 정답 목록이 아니다. 현재 설계는 발화 존재나 보호자 터치이며, 손 흔들기 등을 자동 인식한다고 주장하지 않는다. 몸짓 참여 때 보호자가 진행할 수 있다.
5. 입력 후 해당 행동을 한 번 끝내고 지정 대사로 돌아간다. 입력 전 시범에서 같은 완성 반응을 이미 끝내지 않는다.
6. 무응답은 실패가 아니다. 다시 듣기·보호자 진행을 제공한다. 이름이 길거나 개념이 낯선 목표는 전체 예시 뒤 선택적으로 뜻 덩어리/이름 재청취를 제공하고 단어마다 같은 간격으로 읽지 않는다.
