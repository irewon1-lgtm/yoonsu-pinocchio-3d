# 12화 마지막 여덟 컷

`build.py`는 제작에 사용한 RGBA 원화와 학교 그림을 받아 C43–C50의 투명 전신 셀과 카메라·동작 데이터를 등록한다. 입력 원화는 이 폴더의 `source`와 승인 인물 원화의 `human/source`에 있다. 배우의 발 기준점과 가방, 깃털 모자의 위치는 이전 컷에서 이어진다.

- C43은 C42의 사람형 윤수, 제페토, 귀뚜라미, 요정과 같은 셀 이후에 시선을 바꾼다.
- C44는 요정이 지팡이를 내리고 아이가 윤수에게 말하는 자세로 끝난다. P09 수용 이후 C45 17프레임부터 아이가 손을 들어 올린다. 요정은 32프레임에 답하고 59프레임부터 지붕 위로 물러난다.
- C46의 좌측 경첩은 같은 위치에서 움직인다. 학교 외벽은 승인된 와이드 원화와 일치한다. 점차 넓어지는 개구부 뒤로 새로 그린 교실 내부가 드러난다.
- C49에서 교사가 옆으로 물러나고 아이가 앞발에 체중을 싣고 문턱을 넘는다. 문턱 안에서는 교사와 문틀이 아이보다 앞에 있으며, 마지막 발걸음은 C50의 그늘에서 이어진다.
- C50은 실제 U044 종료 뒤에만 엔딩 표시를 노출한다. 기존 음악 3초와 학교 전경으로 멀어지는 촬영을 사용한다.

이 범위에는 12개 본편 대사가 있고 P09 외부 모델은 본편 시간에서 제외한다. 원화와 각 컷의 실제 대사 재생은 기존 촬영기의 별도 검수 기준을 사용한다.
