# 12화 C35~C42 손과 모자 동작

2D 카메라의 기존 학교 배경에서 손 살피기, 손가락 굽혔다 펴기, 맞잡기와 놓기, 모자 바로 쓰기를 촬영한다. 기존 휴먼 원화의 머리, 몸, 가방과 두 발의 기준점을 사용한다. 새 손 원화의 투명 영역을 정리해 손목 단면을 기준으로 등록했고, 걷거나 다가가는 별도 동작 없이 실제 어깨·팔꿈치 길이에 따라 팔의 자세를 푼다. 소매는 원화의 옷감을 그대로 회전한다.

- C35 첫 컷은 C34 마지막 아동 셀과 픽셀 단위로 일치한다. 귀뚜라미도 C34 착지 셀을 이어받는다.
- P07 대기 중 두 손 사이 간격은 무대 좌표로 13.6픽셀이다. 수락 뒤 두 손의 겹침은 39픽셀이다. 두 대사의 실제 끝 이후에 접촉을 풀고 각자의 휴지 자세로 돌아간다.
- P08 수락 뒤 양손이 같은 빨간 모자의 좌우 가장자리에 닿는다. 붙잡은 상태에서 −3.2°부터 0°까지 움직이고, 가방끈을 확인해 두 손을 내린다. C42 마지막 자세는 C43 원화와 이어진다.
- 편집에서 음성 10개와 외부 모델 4개의 길이를 실제 PCM 파일로 읽는다. 모델과 보호자 대기는 본편 시간에서 빠진다.
- `contact-geometry.json`에 기본 cels의 접촉과 비접촉 측정값이 있다. 극장용 풀 씬 검사는 전체 편집 출력에서 수행한다.

## 생산 명령

저장소 루트에서 실행한다. `build.py`는 `build/layout-hands.json`, `build/motion-hands.json`와 등록 원화를 만든다. 이전 포옹 구간의 마지막 연결 그림과 변신 후 승인 휴먼 원화가 필요하다.

```sh
python3 -B scenes/S12/v3/art/hands/build.py
python3 -B scenes/S12/v3/art/hands/check_pose.py \
  --edit /workspace/scratch/s12-full/pcm-clock/edit.json \
  --out /workspace/scratch/s12-full/hand-verified
```
