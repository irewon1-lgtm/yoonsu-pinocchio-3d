# 학교 앞 구조 후 연기

12화 V3 정본에 따라 구조가 끝난 뒤의 C15–C19를 기존 S11 2D 카메라에서 재생한다. 학교 배경·문·안내판·교사와 귀뚜라미는 실제 등록된 S11 자산을 쓴다. 피노키오가 귀뚜라미에게 몸을 낮추는 프레임은 기존 목각 원화에서 제작했다. 제페토의 허리와 어깨가 움직이는 프레임은 발의 기준점을 유지한다. 대사에 쓰이는 각 말하기 셀은 그림 전체를 등록한다.

```sh
python scenes/S12/v3/art/rescue/build.py
```

|항목|상태|증거|
|---|---|---|
|C06–C14 구조 및 I21 결과 동작|BLOCKED_LAYOUT|마지막 S11 실재생 프레임과 S07 원본 `production/art/raw/plate-school-open.png`에 안내판이 쓰러질 자리를 둘러싼 낮은 오목부와 지지 턱이 없다. 안내판의 축은 기준점 `(413, 597)`이며 화분의 오른쪽 끝은 약 `x=334`, 출입구 왼쪽 문틀은 약 `x=630`이다. 화분과 문틀 사이 안내판 근처는 열린 길이다. 뒤에 기존 벽은 있지만 좌우 통로가 열린 채다. 현재 원화에서 한 번의 바람과 회전만으로 길을 막고 육체를 누르지 않는지 입증할 수 없다.|
|C15–C19 학교 앞 연기|제작|`build/layout-rescue.json`과 `build/art/cels/S12R-*`를 S11 카메라에 연결한다. C18에서 제페토가 살피는 모습을 먼저 보여 주고 피노키오는 자기 차례까지 선 자세를 유지한다. C19에서 피노키오가 몸을 낮추고 귀뚜라미의 디딤을 살핀 뒤 제페토에게 돌아본다.|

최종 C19는 나무 인형 피노키오 `(541, 630)` 높이 236, 제페토 `(667, 629)` 높이 315, 귀뚜라미 `(479, 636)` 높이 84, 안내판 `(413, 597)` 높이 84, 교사 `(739, 559)` 높이 193을 남긴다. 컷이 바뀌어도 문의 위치와 학교 원화는 같다.

C16은 대사 이전 36프레임과 대사 이후 12프레임을 사용한다. C18과 C19의 첫 동작은 각각 96프레임과 72프레임의 편집 시간 안에서 진행한다.

기존 S11 카메라에서 1920×1080·24fps 그림 검수본을 실제 생성했다. C15–C18의 발 위치와 학교 소품, C18에서 피노키오가 서 있는 대기 자세를 확인했다. C19는 손 그림을 보완한 뒤 336프레임만 다시 출력했다. 수락 직후 서 있는 그림, 손이 낮아지는 중간 그림, 손을 편 그림, 그리고 C20으로 넘기는 자세를 해당 MP4에서 추출했다. 이 검수에서는 음성을 넣지 않았으며 Android 입력은 실행하지 않았다.

## C49 교사의 문턱 동작

`teacher_support.py`로 S11 교사 셀 6장의 발 기준점을 등록했다. 교사는 원래 위치 `(739, 559)`에서 앞발을 붙인 채 왼쪽으로 물러선다. 뒤꿈치가 기존 돌 문턱에 닿은 뒤에는 뒷발 기준점 `(710, 565)`에서 서 있다. 4초·96프레임의 별도 1080p 검수본에서 문턱과 교사의 동작을 확인했다. `build/teacher-support.json`은 이 동작을 합성할 때의 시간과 기준점을 담는다.

승인 학교 문 레벨의 8개 셀 중 0번이 가장 많이 열린 상태다. 문짝과 오른쪽 문틀 사이로 보이는 폭은 기존 1280×720 무대에서 약 19픽셀이다. 검수본에서 교사는 이 공간을 가리지 않는다. 인간형 피노키오의 실제 통과는 검증되지 않았다.
