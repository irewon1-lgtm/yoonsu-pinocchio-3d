# S12 V3 학교 구조 제작

사용자가 새 배경 제작을 승인한 뒤 학교 왼쪽 창 밑에 낮은 받침과 양쪽 돌출면을 배치했다. 이미지 생성 입력으로 기존 학교 판을 사용했고, 회차의 창·문·교사 위치와 1280×720 무대 좌표를 이어받았다. 새 돌 원화의 알파 경계는 제작 등록 단계에서 정리했다. 학교 안내판과 모든 등장인물 원천은 기존 S11/S12 얼굴·의상·스프라이트다.

`python3 -B scenes/S12/v3/art/rescue/full/build.py`로 새 그림과 등록을 재생성할 수 있다. 이제 C06–C14에 실제 셀을 공급하는 경로는 `build/layout-rescue-full.json`, `build/motion-rescue-full.json`, `build/art/S12X-school-recess.png`, `build/art/cels/S12X-*`다.

- C06은 귀뚜라미가 뒤 공간으로 피하는 동작, 안내판이 넘어져 선반에 걸리는 동작을 분리했다. 안내판의 움직임과 학교 받침은 동일 무대 좌표다.
- C08에서 피노키오가 발을 옮겨 낮게 앉고 C10에서 제페토가 돌 모서리 바깥으로 한 번 손을 내민다. 움직임이 필요한 C06·C08·C10에 합계 84프레임을 추가했다.
- I21에서 기다리는 동안 안내판은 그대로 있다. 수락 뒤에만 접근→디딤→두 손 접촉→한쪽 들기→귀뚜라미의 측면·앞쪽 이동→안정된 받침으로 복귀→손 놓기 순서로 진행한다. C12·C13·C14 그림은 각각 192·192·216프레임이다.
- 원래 표지판 받침과 네 인물의 학교 좌표를 보존했다. 마지막 C14와 이미 제작했던 C15의 표지판·피노키오·제페토·귀뚜라미는 등록된 전체 알파 그림의 픽셀 값이 같다. 카메라가 넓어지는 컷의 배경 차이는 기존 C15 파일을 건드리지 않고 유지했다.

`check_native.py`로 1,476프레임·498개의 실제 노출과 현장 대사 8개의 입 움직임 등록을 점검했다. `verify_geometry.py`에서 양손 접점과 이동 순서, 문틀 좌표, 판 지지축과 복귀 그림을 검사한다. 지지축의 이동은 0에 가까우며 판의 자유단이 무대 좌표에서 13.50픽셀 올라간다. 이는 2D 그림과 좌표의 확인이며 중량이나 물체의 부피가 있는 힘 시뮬레이션까지 증명하지는 않는다.
