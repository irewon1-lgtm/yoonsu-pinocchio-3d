# 12화 인간형 윤수 원화와 변신

인간형 원화는 C29 피노키오의 목각 그림을 참조해 제작했다. 원본과 등록한 PNG를 `source/`에 함께 보관한다. 같은 빨간 모자, 깃털, 가방, 옷과 신발을 유지했다. 눈을 뜨는 그림과 말하는 입 모양 두 장은 해당 부위만 바뀐다. 등 뒤 가방을 그린 오른쪽 뒤돌기 자세는 학교 입장에 쓰는 별도 원화다.

- 등록 원화 단계 `S12HN-character`, 눈을 감은 모습 0번, 눈을 뜬 모습 1번, 뒤돌아 디디는 자세 2번.
- 한 장에 투명 RGBA 453×755. 기준점 `[223, 665]`, 기준 키 583픽셀. C30 무대 위 좌표 `[561, 643]`, 키 236픽셀.
- C30은 직전 컷의 목각 원화를 첫 그림으로 쓰고, 같은 발 위치에서 발끝, 다리와 몸통, 팔과 손, 얼굴 순서로 바뀐다. 코는 외곽선을 하나로 유지하며 짧아진다. 무대는 처음에 C29 구도를 잇고 이후 얼굴과 손 쪽으로 좁힌다.
- 몸 변신은 C30 내레이션 전에 마무리한다. 이어지는 동안 빛이 사라지고 표정과 어깨가 안정을 찾는다. 다음 컷은 같은 인간형 원화에서 눈을 뜬다.

```sh
python3 -B scenes/S12/v3/art/human/normalize.py
python3 -B scenes/S12/v3/art/human/transform.py
```

측정된 편집 시간과 원화 위치는 `build/motion-transform.json`, `build/layout-transform.json`에 기록된다. 다른 컷은 원화와 기준점 데이터를 사용해 컷마다 손짓과 시선을 다시 제작할 수 있다.
