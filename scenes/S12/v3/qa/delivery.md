# 12화 「친구를 구한 진짜 아이」 V3 검수 기록

12화 본편과 앱 반영은 미완료다. 기존 2D 엔진에서 영상 두 구간 20컷을 완성했다.

| 11화 마지막 화면에서 12화 첫 화면으로 이어지는 원화 | PASS | 원본 2D 합성 RGB 2,764,800바이트가 일치한다. |

| 50컷 본편 연속 재생, 기존 앱 반영 | BLOCKED_RESOURCE | 구조와 변신 이후 최종 프레임이 필요하다. |

귀뚜라미 N012의 “hurt”가 “heard”로 인식된 시안을 제외하고 같은 음색으로 다시 합성했다. 후속 음원은 두 Whisper 모형과 독립 인식기에서 “hurt”로 확인했다. 제페토 U031의 “Pinocchio”도 다시 합성해 두 인식기의 단어 일치를 확인했다.

신규 2D 자료에는 등록 좌표와 원본 해시가 포함된 투명 RGBA 셀 996개가 들어 있다. 본편 컷 제작과 조연 동작 검수용 셀을 함께 담았다. 검사 결과는 각 파일의 실제 범위를 따른다.
