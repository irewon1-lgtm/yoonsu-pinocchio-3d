# 윤수 피노키오 — 12장면을 하나로 잇는 연속성 설계

**상태: REVIEW_REQUIRED · 의미·연출 검토: DESIGN_REVIEW · 실제 영상 연결: NOT_RUN**

이 문서는 5화 상세 설계와 함께 작성한 **S01–S12의 연결 계약**이다. 12개의 독립 이야기를 새로 시작하는 구성이 아니라, 피노키오가 태어난 저녁부터 두 번째 아침 학교에 들어가는 순간까지 한 가지 경험이 다음 경험을 일으키도록 한다. 원본 V1.1의 사건·대사·등장인물·결말은 보존한다. 6–12화의 상세 대본이나 영상까지 제작했다는 의미는 아니다.

기계가 읽는 대응 파일은 [STORY_CONTINUITY_S01_S12.json](STORY_CONTINUITY_S01_S12.json)이다. `scenes`는 12장면의 입장·퇴장 상태, `transitions`는 11개 경계, `motifs`는 반복되는 단서, `local_handoffs`는 이번 5화 전후의 구체적인 인계를 기록한다. 후속 각본과 편집은 이 상태를 받아 이어 써야 한다.

## 1. 변하지 않는 중심 이야기

**사랑으로 태어남 → 몸과 친구를 알아감 → 학교와 귀가를 약속함 → 길을 배우며 이동함 → 음악에 이끌려 잠깐 우회함 → 계속 관람하며 시간을 놓침 → 결과를 마주하고 두려워함 → 가족 앞에서 망설임 → 거짓말의 결과를 경험함 → 사실을 말하고 사과함 → 같은 유혹 앞에서 다른 선택을 함 → 친구를 돕고 학교에 들어감.**

5화의 역할은 약속을 잊게 되는 출발점을 만드는 것이다. 처음부터 학교를 싫어하거나 제페토를 속이려는 아이로 바꾸지 않는다. 학교를 기대하던 마음이 있는 상태에서 소리를 듣고, 정체를 찾고, 흥미로운 무대를 보고, **“잠깐만 보면 괜찮겠지”**라고 생각하는 작은 미룸을 보여준다. 6화의 몰입과 7화의 후회는 그 선택에서 생긴다.

음악·놀이·호기심 자체를 잘못으로 다루지 않는다. 11화에서는 같은 공연을 “방과 후 할아버지와 함께” 즐길 수 있다고 제안한다. 6화에서 핍을 도운 행동도 선행으로 남는다. 학교를 놓친 이유는 구조 자체가 아니라, 그 후에도 계속 머물며 약속을 잊은 선택이다. 12화의 귀뚜라미 구조는 이 경험을 자발적인 배려로 발전시킨다.

## 2. 시간과 장소의 큰 흐름

| 구간 | 이야기 속 시간 | 주요 장소 | 시간 연결 원칙 |
|---|---|---|---|
| S01 | D0 저녁 → D1 아침 | 제페토 작업실 | 기존 완성본의 밤에서 아침으로 바뀌는 전환을 그대로 수용 |
| S02–S05 | D1 첫 아침 | 작업실 → 집 앞 → 학교 길 → 마을 광장 | 같은 아침의 연속된 행동. 새 아침·새 출발로 리셋하지 않음 |
| S06 | D1 오전 → 오후 | 같은 빨간 천막 무대 | 공연에 머무는 동안 빛·그림자·관객 상황으로 시간 경과를 명확히 표현 |

본편 재생 길이와 이야기 속 시간은 다르다. S06의 오후 경과는 실제 행동과 편집으로 전달한다. 윤수의 발화 대기나 반복 재생을 “하루가 지났다”는 근거로 사용하지 않는다.

## 5. 이번 5화의 첫 장면 — S04에서 받는 것

**직전 컷:** `scenes/S04/scene_design_v2.json`의 `B10-C05`의 수정 후 본편 구간(최신 시작·끝은 S04 설계 JSON 참조). 두 인물은 학교 길에서 낯선 소리에 귀를 기울인다. 인형극·천막·소리의 근원은 보여주지 않는다.

**S04 마지막 원문:** “But then, he heard a strange and wonderful sound.”  
**S05 첫 원문:** “Cricket, what's that sound?”

S05 `B01-C01`은 그 질문으로 이어지는 몸과 시선을 받는다. 물웅덩이는 이미 건넜고 신발은 말라 있다. 모자는 머리에, 책은 묶인 가방 안에 있다. 귀뚜라미는 지면에서 동행하며 다시 자신을 소개하지 않는다. 학교 목적지를 잊거나 숲으로 장소를 바꾸지 않는다.

마지막의 희미한 소리는 끊고 다시 재생하지 않는다. “Listen carefully.” 뒤에 북·피리만 잠시 들리는 구간을 확보한다. I08 전에는 음악만 듣고 천막 전체를 보지 못한다. 큰 나무와 잎 사이 천·리본 일부를 시각 단서로 쓸 수 있다.

| 기존 이벤트 | 전제 | 해제 후 원본 반응 | 재개 원문 |
|---|---|---|---|
| I08 / “I hear music!” | “What do you hear?” 종료, 천막 전모는 가림 | 귀뚜라미 귀 기울임 → 피노키오 고개 회전 → 잎 움직임과 음악이 또렷해짐 | “It's coming from the village square.” |
| I09 / “Look over there!” | “Yoonsu, where should Pinocchio look?” 종료, 나무가 천막 전면을 가림 | 카메라 팬 → 천막과 움직이는 무대 인형 공개 → 두 눈이 커짐 | “Wow! A puppet show!” |

추가 참여는 관찰, 안전한 이동, 소품 관리에 연결한다. 윤수에게 “학교를 가지 말라”거나 “공연장에 가라”는 선택을 지시하게 하지 않는다. 잠깐 보기로 결정하는 주체는 피노키오다.

## 6. 이번 5화의 끝 — S06에 넘기는 것

5화는 무대를 발견한 뒤 곧바로 끝내지 않고, 피노키오가 약속을 떠올리면서도 관객 곁으로 이동하는 과정을 보여준다. 관객 오른쪽 바깥 통로를 따라 실제로 무대 앞 오른쪽 모서리의 안전자리까지 걸으며 B09~B10에서 그 위치를 유지한다. 가방은 다른 관객에게 닿지 않도록 **멜빵을 유지한 채 몸 앞으로** 옮긴다. 책은 S03에서 제페토와 펼쳐 본 뒤 가방에 넣은 같은 책이며, 그 이후 여기서는 꺼내거나 펼치지 않는다. 귀뚜라미는 같은 쪽 발치에 있고 마라는 무대 왼쪽에서 북을 두드리되 아직 말하지 않는다.

**S05 마지막 원문:** “But sometimes, one little minute can turn into a very long time.”  
**S06 첫 원문:** “Welcome, everyone!”

이 마지막 내레이션 뒤에도 같은 북소리를 이어 S06 원본 `S06-C01`의 무대·동물 관객·마라로 연결한다. 새 오프닝·중간 암전·설명용 회상은 넣지 않는다. S05에서 해가 져 버리지 않게 하고, 공연에 오래 머무는 시간 변화는 S06에서 전개한다.

### 닫힌 커튼과 I09 공개를 함께 보존하는 방식

원본 I09는 빨간 천막과 움직이는 무대 인형들을 보여 주지만, S06은 본무대 커튼이 닫혀 있고 I10에서 처음 열린다. 이를 잇기 위한 **추가 공간 배치 제안**은 다음과 같다.

- 본무대 커튼은 닫혀 있다.
- 그 앞 무대턱의 **이름 없는 작은 인형 두 개**가 짧게 몸을 흔들어 공연을 알린다. 이후 가림판 뒤로 숨지 않고 **관객 시점 오른쪽 앞턱의 노출 대기 위치**에 남아 S06-U003 “Look at all those puppets!”의 시선 대상이 된다. 핍이 아니며 새 이름·성우·별도 사건을 추가하지 않는다.
- 핍의 얼굴과 이름 소개, 마라의 환영 대사, 커튼 고장과 I10 개방, 핍의 위험과 I11 구조는 6화에 남긴다.

이 제안은 원본을 연결하기 위한 설계이며, 기존 영상에서 확인된 사실이 아니다. 실제 콘티와 렌더에서 인형들의 앞뒤 공간과 닫힌 커튼이 동시에 읽히는지 확인해야 한다.

| S05 종료 / S06 시작 상태 | 유지값 |
|---|---|
| 시간·장소 | 같은 D1 오전, 같은 광장·천막·관객 위치 |
| 피노키오 | 목각, 정상 코, 빨간 모자 착용 |
| 책가방·책 | 가방은 멜빵을 유지해 몸 앞에 착용. S03에서 펼쳐 본 뒤 넣었고 이후 꺼내지 않은 같은 책이 안에 있음 |
| 귀뚜라미 | 피노키오와 같은 쪽 발치, 걱정하는 감정 |

## 7. 앞에서 심고 뒤에서 회수하는 단서

| JSON motif | 앞에서 심는 의미 | 뒤에서 회수하는 의미 |
|---|---|---|
| `PROMISE` | S03 등교·귀가 약속, S05의 의식적인 미룸 | S07 결과, S10 정확한 고백, S11 실천, S12 요정의 확인 |
| `MUSIC` | S04 미확인 소리 → S05 북·피리 → S06 공연 | S10에서 실제 있었던 일을 말함. S11 같은 테마를 듣고도 “Not today!” 선택 |
| `SCHOOLBOOK` | S03 제페토가 가방에 넣어 준 책 | S08–S09 사용하지 않은 책이 사실의 단서. I19에서 스스로 챙김 |
| `HELP` | S02·S04에서 도움을 받음 | S06 핍 구조, S12 친구 구조로 남을 돕는 행동이 자람 |
| `TRUTH_AND_BLUE_LIGHT` | S01 요정의 친절·진실 가르침 | S09 결과 → S10 고백·사과·화해 → S12 바뀐 행동의 확인 |
| `HAT_BAG_IDENTITY` | S03부터 같은 모자·가방을 사용 | 모든 이동과 S12 인간 변신 뒤에도 같은 물건으로 정체성을 유지 |

S11의 음악은 S05와 같은 북·피리 모티프로 지정하되, 실제 음원 생성이나 재생 검증은 아직 하지 않았다. 동일 테마가 들리면 장소를 다시 설명하지 않아도 아이가 이전 선택을 떠올릴 수 있도록 하는 연출 의도다.

## 8. 후속 장면을 만들 때 반드시 해소할 연결 문제

| 위험 ID | 현재 발견한 연결 위험 | 후속 상세 설계 의무 |
|---|---|---|
| R01 | S05의 인형 공개가 S06 커튼 개방을 선점할 수 있음 | 앞턱 맛보기와 닫힌 본무대 공간을 분리하고 I10까지 개방하지 않음 |
| R02 | S06에서 몇 분 보고 갑자기 하루가 지난 것처럼 보일 수 있음 | 공연의 서로 다른 행동과 빛·그림자·관객 변화로 시간 경과를 전달. 반복 루프로 분량을 채우지 않음 |
| R03 | S08의 중심 대화에는 없던 귀뚜라미가 S09에서 갑자기 말할 수 있음 | 집까지 함께 온 동선을 유지하고 첫 발화 전에 문/창 가까이의 짧은 비언어 이동으로 위치를 확인 |
| R04 | 안경을 계속 쓴 제페토가 I15에서 안경을 찾는 모순 | 식탁 전에 벗어 놓은 상태를 보이고 I15 뒤에 착용. 기존 모델의 기본 상태에 맡기지 않음 |
| R05 | S09의 가방 속 책이 S11에서는 창턱에 있음 | **새 연결 제안:** S10 잠자리 전에 닫힌 책을 가방에서 꺼내 창턱에 놓는 짧은 무언 동작. 원본 대사·사건으로 오인하지 않게 변경표에 기록 |
| R06 | S11에서 학교 입장이나 엔딩을 하면 S12가 다시 시작됨 | S11은 열린 학교 문 바깥 작별로 종료. S12 구조 → 요정 → 변신 → 입장 순서 유지 |
| R07 | 매 장면 제목·인사·요약으로 이야기가 반복됨 | 각 장면이 전 장면의 마지막 목적과 자세를 받아 다음 행동으로 넘어가게 함 |

S08 원본의 “여기에는 윤수 질문을 넣지 않는다”는 **망설임 구간**을 보호한다. V2 정책에 따른 참여 10회는 집에 들어오고 식사를 준비하는 다른 행동에 배치해야 한다. 미래 장면의 참여 수를 맞추려고 진실 고백 직전의 침묵을 끊지 않는다.

## 9. 검토와 제작 상태를 구분하는 기준

| 검증 범위 | 이 문서의 현재 상태 | 실제 제작에서 필요한 증거 |
|---|---|---|
| 원본 경계와 12장면/11연결 구조 | 구조 검사 대상 | JSON 순서, 원본 제목·해시, 앞뒤 원문 앵커 |
| 원인·결과와 감정의 자연스러움 | DESIGN_REVIEW / 사용자 검토 필요 | 상세 대본과 콘티의 연속 독해, 이후 전편 재생 |

| S06–S12의 비언어 연결 | 후속 상세 설계 필요 | 사건별 타임라인과 원본/추가 동작 변경표 |
| 귀뚜라미 음성 | 승인 음원 BLOCKED_RESOURCE | 승인된 동일 캐릭터 음원과 실제 발화 검수 |
| S12 최종 인간 외형 | 승인된 `CHAR_YOONSU_HUMAN` 사용 계약 | 승인 참조와 실제 변신 영상·인간형 유지 검수 |

자동 검사가 JSON 항목 존재와 순서를 통과하더라도 이야기가 자연스럽게 재생된다는 뜻은 아니다. 현재 완료 범위는 **연속성을 검토할 수 있는 설계 작성**이며, 영상·음원·기기 재생 검증은 별도다. 5화의 구조 검증 결과와 실제 실행 로그는 5화 QA 문서에서 관리한다.
