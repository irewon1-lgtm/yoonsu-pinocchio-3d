> **제작 대상** 독립 Android 2D 대화형 동화. 대본 V1.1·12장면·21개 발화 원본을 그대로 보존.

> **원본 파일 SHA256** `eb5ca04f5e4302d4a71726f1a24b6cead5cec682b96baee600f6eef8ee951d3e`. V1.1 대본 보존본에 대한 해시이며 채팅 WritingBlock 바이트 동일성 검증을 뜻하지 않음.

## 0. 도면 좌표 및 카메라 공통 표준

- 기준 화면: 가로형 가상 캔버스 1920×1080 (16:9). 좌표는 픽셀 대신 **상대값 0–1**로 저장; 태블릿에서는 16:10 화면에 맞춰 배경 확장 또는 여백 처리하며 인물을 자르지 않는다.
- 안전 영역: 중요 인물 얼굴, 코, 손, 필수 시각 단서와 마이크 아이콘은 중앙 88% 폭/86% 높이 우선. Android 시스템 바·노치·자막과 겹치지 않도록 별도 UI 오버레이.
- 카메라 컷: `WIDE` 공간/동선, `MEDIUM` 인물 중심, `TWO_SHOT` 관계, `CLOSE` 표정, `INSERT` 사물, `WAIT` 윤수 질문 시점, `REACT` 발화 후 사건.
- 장면 전환: 원본 장면 순서 그대로, 일반은 컷 또는 부드러운 페이드; 시청자 질문 중에는 화면 고정, 사건 완료 후 후속 원문 대사로 복귀.
- 동작 속도: 대사 길이 미확정이므로 초 단위 고정 타임라인으로 대사 자르지 않음. 코 성장 `I14` 약 2.2초·코 축소 `I18` 약 2초는 원본 그대로.
- **일러스트**: 현재 SVG 컷 이미지는 배치·소품·카메라 검토용 **와이어프레임/프록시**이며 최종 원화가 아님. 캐릭터 얼굴·관절·배경 스타일은 3단계 승인 후 생산.
- **스토리 인터랙션**: 내용 인식 STT 없음. 질문 끝 → 발화 감지 및 발화 종료 확인 → 반응 클립 1회 → 원본 지정 대사로 복귀.

## 4. 사전 검수 PASS 기준

- 누락/중복 없이 12장면·358 영어 음성 대사·53개 원본 연출 지시·21개 발화 이벤트 컷 배정
- `I01`~`I21` 각각 WAIT 1개와 바로 이어지는 REACT 1개가 존재
- WAIT 발화 질문 = 원본 `trigger_speech_id`, REACT 재개 대사 = 원본 `resume_speech_id`
- S08 (긴장 형성 장면)은 윤수 발화 0개로 보존
- I14 WAIT 코 정상 / REACT 코 성장, I15 이미 긴 코, I18 WAIT 긴 코 / REACT 정상 코로 복구
- 기존 I01~I20 및 S01~S11 대사 원본 보존; 새로운 S12는 승인 V1.1 그대로 읽기 전용
- I21 WAIT/REACT에서는 피노키오 목각·귀뚜라미 trapped→rescued, 마법은 구조와 요정 대사가 끝난 뒤 진행
- S12-U028에서 목각→CHAR_YOONSU_HUMAN 전환; S12-U029부터 인간형 유지; 실제 윤수 원화 미제작
- S11 후반 기존 엔딩 9줄을 삭제한 것이 아니라 S12 변신 뒤로 이동
- 대본 문장 수정·새 영어 대사 추가 금지
- 파일 해시 및 ZIP 내부 파일 해시 기록

- 실제 영어 WAV·효과음·입모양 동기화: **미착수**
- Godot·APK 빌드·Galaxy Tab S10 FE 기기 테스트: **미착수**
- 이 단계는 **스토리보드 구조/레이아웃 설계 PASS**이고 **그림/UI 최종 디자인 승인 PASS**가 아님.
