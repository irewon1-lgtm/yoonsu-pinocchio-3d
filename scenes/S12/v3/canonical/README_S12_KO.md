# 피노키오 S12 제작 인계 V2 — 친구를 구한 진짜 아이

2026-11-25 · 작성물 수정 V2 · 대본·명세 수정 완료 / 실제 미디어 미제작

## 현재 결과

12화의 변신 직후 손 과제 두 번이 첫 환희를 늦추던 배치를 수정했다. **변신 → 피노키오의 첫 기쁨 → 제페토의 감격 → 서로의 포옹과 변함없는 사랑 → 귀뚜라미의 축하**를 먼저 이어 주고, 포옹이 풀린 뒤 손 탐색 참여를 진행한다. 요정의 고정 음색 식별자를 앞선 화와 맞췄으며, 윤수에게 행동의 뜻을 먼저 보여 주는 시범과 구출 공간의 조건부 설계도 보강했다.

영어 문구는 바꾸지 않았다. 원전 44개와 기존 신규 연결 27개를 합친 본편 71개, 화면 밖 따라 말하기 모델 10개를 합친 **81개 작업의 문구·화자가 V1과 동일하다.** 새 음성을 만든 것이 아니라 합성할 대본과 지시를 수정한 상태다.

## 중요한 V2 적용 규칙

1. **대사 ID 숫자순으로 재생 순서를 다시 만들지 않는다.** 첫 감격과 포옹을 보호하기 위해 N020/N021이 N015~N019보다 먼저 나온다. 기존 ID와 문구는 유지했고 재생 순서는 `scene_design_v2.json`과 읽기용 대본이 정한다.
2. U017부터 U033 실제 종료 및 포옹 해제까지 질문·모델·입력을 넣지 않는다. C30 변신 다음 C31 U029/U030, C32 U031/U032, C33 N020/N021, C34 U033으로 연결한다. 첫 손 탐색 질문 P05는 C35에 있다.
3. 의미 시범과 피노키오의 결과 동작을 구별한다. P03은 제페토의 친구 상태 확인, P05는 제페토 자기 손바닥, P06은 제페토 자기 손가락 굽힘, P08은 기운 모자와 제페토의 빈 손바닥 수평 시범이다. 피노키오의 해당 결과 동작은 입력 수용 뒤에 시작한다.
4. C40에서 N023/N024와 실제 손 해제를 끝낸 뒤 C41 모자 질문으로 넘어간다. P05→P06→P07→P08 질문 끝의 본편 계획 간격은 18초·19초·19초다. 실제 대기·모델 시간과 입력 타이머 값이 아니다.
5. 요정의 정식 ID는 `BLUE_FAIRY_EXISTING_C`다. V1의 `FAIRY_EXISTING_APPROVED_C`는 같은 승인 C 참조로 연결하는 별칭이다. 새 목소리나 대체 프리셋을 선택하지 않는다. 피노키오와 제페토는 사용자가 고정한 S03 음색, 귀뚜라미는 기존 음색을 유지한다.
6. 구출 공간은 `assets/S12_RESCUE_LAYOUT_V2.md/json`의 **조건부 설계**다. 실제 승인 학교 배경의 구조가 맞지 않으면 `BLOCKED_LAYOUT`다. 새 벽·장치·소품을 이미 승인된 것처럼 추가하지 않는다.
7. 기존 최종 음원에 맞춘 말하기 입모양 시작·종료와 표정·시선·몸짓을 우선한다. 이번 수정 때문에 정밀 음소 립싱크를 새 필수 작업으로 추가하지 않는다.

## 유지되는 이야기와 상태

11화 마지막의 같은 아침, 열린 학교 문 밖, 정상 코의 목각 피노키오, 같은 빨간 모자·신발·책이 든 닫힌 가방, 제페토의 안경, 발치 귀뚜라미, 아직 서 있는 작은 나무 안내판에서 시작한다. 손잡기는 이미 끝났다. 귀뚜라미는 다치지 않고 I21 이후에만 구조된다.

U027이 끝나기 전 사람 모습이 나타나지 않는다. C30에서 승인된 `CHAR_YOONSU_HUMAN`으로 한 번 변신하되 이름·고정 피노키오 음색·소품은 유지한다. N009의 당일 두려움 고백은 마지막 U040의 `today`와 연결된다. 학교 입장과 U044, 마지막 카메라 이동 뒤 한 번만 완결하며 다음 화 예고나 추가 발화를 넣지 않는다.

## 재생성과 검증 범위

패키지 루트의 `python3 tools/build_s12.py`는 작성 원천에서 대본·작업표·장면·입력 데이터를 재생성하고 구조를 검사한다. 이 명령은 음성 합성이나 영상 렌더를 하지 않는다. 다른 디렉터리에 새로 풀어 재생성했을 때의 재현성은 **전체 인계 패키지의 최종 통합 검증 결과**를 확인한다. 현재 문서의 41개 통과를 그 시험의 결과로 대신하지 않는다.

## 실제 영상 전에 남은 조건

- 실제 승인 S03 피노키오·제페토와 기존 귀뚜라미 참조 파일을 연결한다. 요정·내레이션 참조 파일이 있다고 해서 새 대사 합성이나 청취가 끝난 것은 아니다.
- 실제 엔진이 지원하는 방식으로 대사별 연기를 전달하고, 각 화자의 다른 감정 샘플을 자막 없이 들어 구별되는지 확인한다. 통과한 방식으로 본편과 모델 전체를 만들고 문제가 있는 줄만 재제작한다.
- 승인 인간형 윤수 원화와 기존 목각 원화·리그를 확인한다. 구출 공간은 실제 학교 배경, 귀뚜라미 몸 크기, 판 받침·무게, 손 접촉과 복원 경로에 맞춰 애니매틱으로 확인한다.
- 최종 음원·동작에 맞춰 컷과 입력 경계를 확정한다. 모델 중 마이크 OFF, 실제 모델 종료 뒤 입력 준비, 수용 1회, 반응 완료 뒤 재개가 앱에서 실제로 지켜지는지 확인한다.
- 새 음원 실제 재생, 영상·앱·기기 검증을 완료하기 전에는 실제 연기·발음·움직임 통과로 보고하지 않는다. 이미 요청된 V2 대본 수정을 다시 승인받기 위한 중단 단계는 추가하지 않는다.
