# Codex — 피노키오 마지막 12화 제작 지시 V2 (2026-11-25)

이 패키지의 S12 상세 대본을 기준으로 기존 프로젝트에 마지막 화를 제작하라. 우선 G0 원본·실제 승인 자산·11화 마지막 상태를 검증하고, G1 V2 수정본과 현재 검증 결과를 확인하라. 이번 사용자 요청에 따른 대본 수정은 반영했으므로 같은 수정을 다시 승인받느라 중단하지 말고, 실제 승인 자산과 실행 가능 범위를 확인해 진행하라. 이전 회차·승인 음색·원화·기존 앱 서명/저장 데이터를 임의 변경하지 마라. 이 인계 자료는 실제 미디어가 없는 작성물이다.

## 고정 입력

2. 본편 최소 360초, 계획 468초. 실제 연기 음원과 동작으로 재타이밍한다. 모델·기다림·재시도는 제외. 무의미한 정지 컷이나 반복으로 길이를 채우지 마라.

4. I21 질문 U010 → 모델 `Help the cricket!` → 실제 수용 → 결심·달려감·굽힘·판 들기·친구 탈출·안정·손 해제 → U011. 귀뚜라미는 다치지 않는다. 원본 구조 인과를 잠근다. 학교를 선택했던 11화와 친구 걱정을 표현한 U008을 보존한다. 영어 발음 정확도가 도움이나 인간형 변신의 조건이 아니다.

U027 완전 종료 전 목각·정상 코 유지. C30의 실제 변신에서 승인된 `CHAR_YOONSU_HUMAN` 사용. 승인 원화 없으면 BLOCKED_RESOURCE. 사람형 이후 같은 피노키오 이름·고정 S03 음색·모자·가방·책·신발을 유지한다. U034~U035 축복·응답, U036~U044 최종 인사 및 학교 입장 구간에 추가 입력을 넣지 않는다. U044와 학교 입장·최종 카메라 이동 완료 후 정확히 한 번 엔딩 처리.

## 음성: 이전 실패 방식 반복 금지

71개 본편 + 외부 모델 10개 = 총 81개. 피노키오/제페토는 최종 S03 승인, 귀뚜라미는 기존 고정, 파란 요정은 기존 C, 내레이션은 기존 A. 변신 후 목소리도 동일하다. 파란 요정의 ID는 S10과 같은 BLUE_FAIRY_EXISTING_C이다. 기존 S12 별칭 FAIRY_EXISTING_APPROVED_C는 이 ID로만 연결하라. 요정 C와 내레이션 A의 참조 MP3·해시는 패키지에 연결했다. 피노키오·제페토의 최종 S03 및 귀뚜라미 참조는 BLOCKED_REFERENCE 상태이므로 실제 승인 파일을 확인하기 전 임의 캐스팅하지 마라.

IndexTTS2 등 감정 제어형 엔진은 실제 설치·모델 파일·지원 제어의 사용을 확인한 후 사용하라. 이전 IndexTTS2 가중치 다운로드 403 문제는 현재 환경에서 실제 해결 여부 확인. 기존 Kokoro 낭독에 단순 피치·속도·음량 보정만 하고 감정 연기가 되었다고 보고하지 마라. 감정 지시/화자 참조/정확한 영어 문구를 분리해서 모델의 지원 입력 경로에 전달하라. 지원하지 않는 인수를 발명하지 마라. 영어 이외의 지시를 읽지 마라. 원문 밖 감탄사·웃음·비명 추가 금지.

대표 10개만 먼저 합성한다. 각 화자 내 대비를 확인한다.
- 피노키오 U005 걱정 ↔ U029 폭발적인 환희
- 제페토 U010 침착한 부탁 ↔ U031 놀라움과 감격
- 귀뚜라미 U003 갑작스러운 다급함 ↔ U011 구조 후 안도와 감사
- 파란 요정 U019 따뜻한 인정 ↔ U027 경이로운 마법의 약속
- 내레이션 U002 예상 밖 긴장 ↔ U028 변신의 감동

실제 생성 결과를 감정 라벨 없이 들어도 의도가 구별되고 음색이 유지되며 발음·첫/끝 자음이 자연스러운지 확인한다. ASR·파형·해시만으로 연기 PASS 금지. 청취 기능이 없으면 NOT_RUN으로 보고하고 비교 음원을 제공한다. 대표 방식이 불합격이면 그 방식으로 81개를 찍어내지 않는다. 음색 변경·유료 외부 전송·비용 발생은 기존 승인 범위 밖에서 진행하지 않는다.

## 2D·입력·완료

assets/S12_RESCUE_LAYOUT_V2.md/json의 구조 배치는 실제 승인 배경에 맞는지 먼저 확인하라. 추상 기하 테스트는 실제 배경 검수가 아니며, 제페토의 현재 접근 경로와 피노키오의 접근 가능한 면을 한 와이드 구도에서 납득 가능하게 보여야 한다. 조건부 배경 구조가 없으면 BLOCKED_LAYOUT로 기록하고 임의의 새 소품을 넣지 않는다.

P03은 제페토의 친구 상태 확인 시범, P05는 제페토 자기 손바닥 시범, P06은 제페토 자기 손가락 굽힘 시범, P08은 기울어진 모자와 빈 손바닥 수평 시범으로 뜻을 먼저 보인다. 피노키오의 해당 결과 동작은 수용 후다. P07의 손잡기 N023/N024 뒤 손을 실제로 놓고 C41의 P08로 넘어가라.

정밀 음소 립싱크 신규 구현을 이번 수정의 조건으로 추가하지 않는다. 자연스러운 연기·발음과 표정·시선·몸짓 일치를 우선한다. timing_budget의 110wpm과 계획 초수는 작성 예산이며 강제 합성 속도나 컷 종료 타이머가 아니다.

기존 승인 S02 계열 2D 제작 경로와 실제 PNG/atlas를 이용한다. 모자·판·손가락·포옹·변신·문턱 동작에 필요한 실제 키포즈 및 중간 프레임을 만들고 물리적 접촉·시선·발 위치·가림을 검수한다. 렌더링 비대상 3D 작업 및 다른 회차 재생성을 하지 마라. 음성 길이와 실제 샘플 수 기준으로 타임라인·기존 말하기 입모양 시작/종료·표정·시선·몸짓을 맞추고 영향을 받는 S12 미디어와 콘텐츠 카탈로그만 변경한다.

10개 참여는 질문 종료→본편 정지→모델 1회(마이크 OFF)→실제 모델 종료→허용된 입력 활성화→VAD 발화 활동 종료 또는 보호자 진행→1회 반응 완료→후속 대사. 검증된 기존 마이크 프로필을 상속하며, 발화 정확도 평가/임의 타임아웃 자동 성공 금지. 중복 콜백/되감기/권한 거부/오프라인/저장 복구를 실제 시험한다.

정본/신규 구조 PASS와 실제 합성·청취·렌더·앱·기기 테스트를 분리한다. 실제 검증 로그, 최종 음원 SHA, 그림과 프로젝트, 완성 MP4와 앱에서 로드되는 버전, 실제 시간(최소 360초), 모든 이벤트 완료 근거를 제공한다. 막힌 자원은 정확한 경로·오류를 기록하고 거짓 PASS를 금지한다.
