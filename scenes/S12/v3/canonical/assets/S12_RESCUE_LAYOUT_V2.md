# S12 구출 공간 V2 — 조건부 배치와 추상 기하 검증

## 상태와 사용 범위

이 문서는 C06~C14와 I21의 **공간·동작 설계**다. 원전 대사와 사건은 변경하지 않는다. 승인 배경, 캐릭터 원화·리그, 실측 크기, 실제 영상은 제공되지 않았으므로 **완성된 그림이나 물리적으로 검증된 애니메이션이 아니다.** 아래 구조가 실제 승인 학교 배경에 맞는지 확인되기 전 상태는 `CONDITIONAL_DESIGN_REQUIRES_APPROVED_ART`다.

함께 제공하는 `S12_RESCUE_LAYOUT_V2.json`에는 조건부 배치, 컷별 계약, 무차원 기하 예제, 그 예제를 검사하는 Python 함수, 실제 실행 결과가 들어 있다. 8개 검사는 추상 예제에만 해당한다. 실제 그림·움직임·음성·앱 통과로 옮겨 적지 않는다.

## 1. 한 와이드 구도에서 보여야 하는 구조

**기존 학교 벽과 문턱/문틀의 돌출 면이 실제로 만드는 낮은 오목한 공간**을 사용한다. 뒤쪽과 양옆은 기존 구조물로 막혀 있고, 앞쪽은 학교 길을 향해 열려 있다. 같은 작은 목판은 그 앞쪽 기존 받침에 서 있다가 바람에 안쪽으로 기울며, 실제로 존재하는 안정된 턱/받침에 걸린다. 귀뚜라미는 판과 닿지 않는 여유 공간에 있다.

이때 판은 귀뚜라미의 몸을 누르는 것이 아니라 **낮은 앞 모서리와 양옆의 좁은 틈 때문에 출구를 막는다.** 피노키오가 접근 가능한 낮은 쪽을 조금 들어 올리면 가장 가까운 측면 모서리에 통과 가능한 틈이 생긴다.

|요소|와이드 구도에서 전달할 정보|승인 자료 확인 사항|
|---|---|---|
|학교 문|피노키오가 가려던 열린 문은 같은 위치에 계속 보인다.|기존 문·문턱·교사·학교 배경 유지|
|뒤쪽/옆 구조 면|귀뚜라미가 뒤나 옆으로 바로 돌아 나갈 수 없는 이유를 보인다.|실제로 존재하는 구조여야 함. 가상의 벽을 승인된 배경처럼 추가하지 않음|
|같은 작은 목판|한 물체의 밑면 회전, 안전한 정착, 들어 올림, 재배치가 연결된다.|기존 목판의 크기·두께·받침·무게에 맞는지 확인|
|귀뚜라미|머리 위·몸 옆 여유가 보이며 다치지 않았다. 가까운 출구만 막혔다.|실제 몸 폭·높이와 동작 실루엣을 기준으로 간격 확인|
|피노키오|판의 접근 가능한 앞쪽 면에 있다.|실제 손이 보이는 두 곳에 닿고, 발을 지지한 채 작은 개방 동작이 가능해야 함|
|제페토|현재 위치는 문틀/옆면 반대편이다. 직선으로 손을 뻗으면 그 면에 가려진다.|손 길이가 짧거나 힘이 없다는 설정이 아님. 현재 위치의 가림이 화면에 보여야 함|
|안전 지점|열린 가까운 측면 바깥에 있고 판을 다시 세울 때의 회전 경로와 겹치지 않는다.|구출 뒤 귀뚜라미가 실제로 이 지점에 도착해야 함|

이 오목한 공간·옆면·지지 턱이 승인 배경에 없다면 예제를 억지로 적용하지 않는다. `BLOCKED_LAYOUT`로 표시하고 **실제 승인 배경에서 같은 인과가 성립하는 배치**를 확보해야 한다. 이 문서는 새 벽·배수로·경첩·덫·악역·장치를 도입하라는 승인서가 아니다.

## 2. 세 가지 ‘왜?’에 대한 화면의 답

### 귀뚜라미는 왜 돌아 나가거나 뛰어넘지 못하나?

기존 뒤쪽과 양옆 면이 공간을 한정하고, 비스듬한 판과 낮은 앞 모서리가 남은 출구를 막는다. 귀뚜라미는 몸을 편히 둘 수 있는 내부 여유 공간에 있지만, 바깥으로 이어지는 틈은 실제 몸보다 작다. 뛰어도 단단한 면을 통과할 수 없다는 구조다. **귀뚜라미에게 갑자기 ‘뛰지 못한다’는 새 성격·능력 제한을 붙이지 않는다.**

판이 조금 들리면 근처 측면 틈의 높이가 귀뚜라미 몸보다 커진다. 이미 막힌 것을 여러 번 보여 주거나 위험한 탈출 시도를 반복시키지 않는다. U006 `I'm okay, but I can't get out!`과 함께 한 번의 명확한 공간 확인으로 충분해야 한다.

### 제페토는 왜 지금 바로 손이 닿지 않나?

제페토의 **현재 접근 면**과 피노키오의 접근 면이 다르다. 제페토가 한 번 손을 뻗으면 기존 옆면이 직접 경로를 가린다. 반면 피노키오는 열린 면에 있다. 손 길이 부족·노쇠함·무능함을 만들어내지 않는다. 제페토가 나중에 위치를 바꾸어 돕는 것은 가능하다.

제페토는 계속 허공을 더듬으며 시간을 보내지 않는다. 한 번 상황을 확인한 뒤 아이와 눈을 맞추고 안전하게 할 수 있는 작은 도움을 지지한다. 아이가 무리한 구조를 하고 어른은 구경만 하는 장면이 되지 않도록 실제 보드 크기와 무게를 확인해야 한다. I21 입력 대기는 앱의 정지 상태이며 위험이 계속 진행되는 실시간 사건으로 묘사하지 않는다.

### 피노키오는 왜 할 수 있나?

열린 접근 면에서 양손으로 실제로 보이는 두 모서리를 잡을 수 있다. 지지된 판 전체를 공중으로 번쩍 드는 것이 아니라 **다른 실제 받침 접촉을 유지하며 가까운 틈만 작게 연다.** 귀뚜라미가 빠져나오는 동안은 높이를 고정한다. 손가락이 판이나 바닥을 관통하면 안 되고, 승인 리그로 이 자세가 안 되면 다른 배치를 찾아야 한다.

**C13 문구의 정확한 범위:** 기존의 ‘판 아래가 아닌 옆 안전 경로’는 ‘판 중앙 밑으로 새로 들어가거나 정면으로 통과하지 않고, 가장 가까운 열린 측면으로 빠져나온다’로 구체화한다. 이 배치에서 귀뚜라미는 처음부터 비스듬한 판 뒤의 여유 공간에 있다. ‘판의 투영 아래를 어느 순간에도 지나지 않는다’는 절대 해석까지 만족한다고 주장하면 안 된다.

원전 영어 대사·I21 문구·질문 종료·감사 재개 위치는 그대로다. 새로운 비명·효과음 대사·보상 문장을 넣지 않는다.

## 4. 무차원 기하 예제의 실제 실행 결과

좌표 단위는 미터·픽셀·프레임이 아니다. 실제 크기를 확보하기 전 **논리의 일관성을 점검하는 가상의 정규화 공간**이다. 귀뚜라미는 반지름 0.06의 구체로 단순화했다. 이 구체는 실제 신체 형태를 대신하지 못한다.

판 길이는 약 0.929, 폭 0.56, 두께 0.03이다. 양옆 면의 안쪽 간격은 0.60으로 판 좌우에 각각 약 0.02가 남는다. 그 틈은 예제의 귀뚜라미 지름 0.12보다 작다. 낮게 정착한 판 각도는 약 -20.484도이며 10도 올린 상태는 약 -10.484도다. 들어 올린 쪽 끝 중심 높이는 약 0.171이다. 이 수치를 실제 연출의 고정 각도나 아이의 발화 지연값으로 사용하지 않는다.

|검사|실행 결과|해석 범위|
|---|---|---|
|닫힌 상태에서 안전 지점으로 가는 3차원 격자 경로|없음|정의한 구체와 장애물, 격자 범위에서만 성립|
|10도 들어 올린 상태의 가까운 측면 탈출 경로|있음, 48개 경로 점|실제 캐릭터 보행·접촉 검증 아님|
|탈출 경로에서 점프 필요 여부|중심 높이 0.08 유지|예제 경로는 높이를 올리지 않아도 통과|
|121개 낙하 각도에서 이미 안전 위치에 있는 구체와 판의 충돌|없음|귀뚜라미가 안전 위치로 이동하는 동작은 별도 검증 필요|
|판이 양옆 면 사이에 들어가는 폭|성립|실제 원화 치수 확인 필요|
|닫힌 좌우 틈이 구체 지름보다 작은지|성립|실제 귀뚜라미의 몸 폭·압축 가능성 확인 필요|
|제페토의 현재 손 경로|길이는 닿지만 기존 옆면에 가림|현재 자세에 한정. 영구적으로 도움을 못 준다는 뜻 아님|
|피노키오의 현재 손 경로|가림 없이 예제 도달 범위 안|실제 양손·손가락·체중 지지는 미검증|

**결과: 추상 기하 검사 8/8 통과. 승인 배경 적합성·애니매틱·실제 움직임은 미검증.** 유한 격자 검사는 모든 연속 경로나 실제 인체를 수학적으로 완전 증명하지 않는다. 질량·중력·마찰·받침 안정성·복원 중 피벗 변경도 시뮬레이션하지 않았다.

재현은 JSON의 `validation_runner_source_python`에서 `validate(fixture)`를 실행하고 기존 `validation_result`와 비교하면 된다. Python 표준 라이브러리만 사용한다.

## 5. 실제 제작을 막는 미해결 항목

아래가 없으면 구출 장면의 시각 품질을 PASS로 기록하지 않는다.

1. 승인된 학교 배경에서 뒤·옆 구조 면과 안정된 받침의 실제 위치·치수.
2. 귀뚜라미의 실제 폭·높이·머리 위 여유·걷기/뛰기 실루엣.
3. 피노키오가 무리 없이 양손으로 잡고 지지된 판을 조금 여는 원화·리그 포즈.
4. 제페토의 현재 직선 접근은 가려지고 피노키오의 접근은 열려 있음을 동시에 보여 주는 와이드 콘티.
5. 떨어지는 판, 고정된 판, 옆 탈출, 원래 받침으로 복원할 때의 실제 전 프레임 충돌 검사.
6. 판의 무게·받침 안정·손 옮김·발 지지·복원 경로를 확인한 실제 애니매틱.

이 조건부 배치는 기존 문장에 없던 물리적 이유를 구체화한다. 다만 실제 배경이 조건을 만족하지 않으면 재배치해야 한다. **설계 구체화 완료와 실제 영상 검증 완료를 구별한다.**
