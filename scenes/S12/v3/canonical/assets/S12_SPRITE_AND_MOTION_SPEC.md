# S12 2D 스프라이트·동작 제작 명세 V2

2026-11-25. 이 파일은 수정된 제작 설계다. PNG·atlas·실제 애니메이션을 생성하거나 청취·렌더 검수를 완료한 결과가 아니다. 기존 승인 S02 계열 2D 엔진과 승인 원화·학교 배경을 사용한다.

## 우선순위

1. 감정이 들리는 연기와 또렷한 발음. 합격한 최종 음성 길이에 동작·응답을 맞춘다.
2. 동작의 인과, 실제 접촉, 시선, 발 접지, 이전 컷의 상태를 이어 받는다.
3. 첫 환희·포옹을 입력 대기로 끊지 않는다. 본편과 외부 모델을 구분한다.

정밀 음소 립싱크를 새로 구현하는 작업을 이번 수정의 필수 조건으로 추가하지 않는다. 기존 말하기 입모양의 시작·종료를 실제 음성에 맞추고, 감정 변화에 맞는 표정·고개·시선·몸짓을 우선한다. 외부 모델 동안 캐릭터가 직접 말하는 입모양은 정지한다.

## 동작 시간과 원화 데이터

본편 계획은 468초, 24fps 환산 11,232프레임이다. 실제 영상 길이·프레임 수는 아직 측정하지 않았다. scene_design_v2.json의 timing_budget은 말과 동작이 들어갈 여유를 살피는 작성 단계 추정이며 재생 타이머가 아니다. 추정 110wpm을 합성 엔진의 일괄 속도 값으로 전달하지 않는다. 질문이 일찍 끝나면 계획 컷 끝까지 기다리지 않고 실제 질문 종료 경계에서 참여로 넘어간다. 연기가 길어지면 영향을 받는 컷·대사 응답·입력 경계를 다시 계산한다.

승인 스프라이트의 canvas, pivot, trim offset, 좌우 손·발·모자·가방·지팡이 socket, atlas region, exposure, draw order를 유지한다. PNG 투명 경계·패킹 회전 지원은 실제 엔진 기준으로 확인한다. 정지 이미지 이동이나 반복 루프로 시간을 채우지 않는다. 최종 음원과 일치하는 말하기 시작·종료, 표정 전환, 상대 반응을 영상에서 확인한다.

## 실제 영상 전 남은 검증

- 구조 장면의 조건부 기하를 실제 승인 학교 배경에 대입하고, I21 전·판 들기·측면 통과·판 복귀를 한 와이드 구도에서 검수한다. 조건이 맞지 않으면 BLOCKED_LAYOUT이며 임의 새 벽·장애물을 추가해 통과 처리하지 않는다.
- C30 승인 인간형 원화와 목각 원화의 정합, C33 서로의 포옹 접촉, C36/C38 손가락, C40 공유 손과 해제, C42 모자, C49 문턱을 최종 프레임에서 검사한다.
- 추상 기하 검사나 작성물 PASS는 실제 자산 접촉·렌더·앱 실행 PASS가 아니다.
