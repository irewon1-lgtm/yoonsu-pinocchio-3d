# S12 V2 수정 기록

2026-11-25 · 수정 범위: 12화 대본 배치·연기 맥락·윤수 의미 시범·음색 참조 연결·구출 공간 명세. 실제 음성·그림·영상·앱은 새로 제작하지 않았다.

## 보존한 내용

V1과 ID별로 비교한 81개 작업의 영어 문구와 화자는 모두 같다. 원전 U001~U044의 문구·화자·순서도 유지했다. 신규 N001~N027과 모델 M001~M010은 ID를 바꾸지 않았다. 10개 참여와 I21 `Help the cricket!`도 유지했다.

N020/N021은 감정의 흐름에 맞춰 N015~N019보다 먼저 재생된다. 이는 번호 오류가 아니라 의도한 배치다. 신규 ID를 숫자순으로 재정렬하면 첫 환희를 끊던 문제가 다시 생긴다.

## F01 — 첫 환희와 가족의 감격을 끊던 참여 배치

**작성물 수정 완료. 실제 연기·영상은 미검증.**

V1은 변신 컷 뒤에 손 보여주기와 손가락 굽히기 참여가 있어 U029의 첫 환희 전까지 본편 36초와 모델·입력 대기가 들어갔다. 제페토가 먼저 손을 확인한 뒤 아이가 처음 소식을 알리는 듯 연기하는 맥락도 생겼다.

V2는 C30 변신→C31 U029/U030→C32 U031/U032→C33 상호 포옹 N020/N021→C34 귀뚜라미 U033과 포옹 해제로 연결했다. U017~U033과 실제 포옹 해제를 하나의 보호 구간으로 묶었다. C35에서 시작하는 손 탐색 참여는 이 감정 장면이 끝난 뒤다. 계획 컷의 남은 시간을 채우려고 U028과 U029 사이에 의무 침묵을 넣지 않는다.

근거: `story/scene_design_v2.json`, `story/interaction_map_v2.json`, `story/S12_AUTHORING_SOURCE.txt`, `story/S12_AUTHORING_METADATA_V2.json`, `assets/S12_SPRITE_AND_MOTION_SPEC.md`.

## F05 — 요정 음색 식별자와 참조 연결

**작성물의 ID·참조 연결 수정 완료. 실제 합성·청취·앱 조회는 미실행.**

정식 ID를 앞선 화와 같은 `BLUE_FAIRY_EXISTING_C`로 통일했다. 기존 `FAIRY_EXISTING_APPROVED_C`는 같은 승인 참조로만 연결하는 별칭으로 남겼다. 요정 C와 내레이션 A의 기존 MP3 바이트·경로·해시가 패키지에 연결돼 있다. 새 성우나 새 음색을 선택하지 않았다.

피노키오·제페토의 S03 고정 음색과 귀뚜라미의 기존 음색 잠금은 유지했다. 이 세 참조의 실제 파일은 아직 `BLOCKED_REFERENCE`다. 임의 대체 음색을 넣어 이 상태를 통과 처리하지 않는다.

근거: `voice/S12_CHARACTER_VOICE_PROFILES.json`, `voice/reference_registry_v2.json`, `voice/references/`, 각 음성 작업의 profile 연결.

## F09 — 윤수에게 뜻을 먼저 보여 주고 결과는 응답 뒤에 실행

**작성물 수정 완료. 실제 이해도·입력 엔진은 미검증.**

- P03: 제페토가 귀뚜라미 얼굴과 발을 살피는 동작으로 상태 확인의 뜻을 먼저 보인다. 피노키오 자신의 확인은 수용 뒤다.
- P05: 제페토가 자기 손바닥을 펴서 보여 준다. 피노키오는 응답 뒤 제페토 쪽으로 자기 손을 펼친다.
- P06: 제페토가 자기 손가락을 굽혔다 펴서 보여 준다. 피노키오는 시범을 본 뒤 질문하고, 수용 뒤 자기 손가락을 움직인다.
- P07/P08: 손잡기와 온기 대사 후 실제 손 해제를 C40에서 끝낸다. C41에서는 기운 모자와 제페토의 빈 손바닥을 수평으로 바꾸는 시범을 보인 뒤 다음 질문을 한다. 모자 정돈은 C42의 수용 후 동작이다.

P05~P08의 질문 종료 계획은 05:22→05:40→05:59→06:18이며 간격은 18초·19초·19초다. 모델·대기·재시도는 이 계획 시계 밖에 있다. 대기 제한을 짧게 하거나 자동 성공을 추가한 것이 아니다. 세 단어 모델 문구는 모두 유지했다.

근거: `story/interaction_map_v2.json`, `story/S12_YOONSU_CUES.md`, C18~C19와 C35~C42의 시범·결과·종료 조건.

## F10 — 구출 공간의 조건부 설계 구체화

**조건부 공간 설계 완료. 실제 승인 배경 적합성과 실제 움직임은 미검증.**

같은 학교의 기존 벽·문틀/문턱 면이 만드는 오목한 공간, 같은 목판과 실제 받침을 전제로 출구가 막히고 가까운 측면 틈이 열리는 조건을 명시했다. 제페토는 현재 접근 면에서 직선 손 경로가 가려지고 피노키오는 열린 접근 면에 있다. 어른을 무능하게 만들거나 귀뚜라미의 점프 능력을 없애는 설정은 추가하지 않았다.

실제 실행한 추상 기하 예제는 8개 통과다. 닫힌 상태의 탈출 불가와 판을 조금 들었을 때 점프 없이 측면으로 나오는 경로 등을 확인했다. **무차원 구체·판·장애물의 예제이며 실제 캐릭터, 실측 배경, 질량·마찰·받침 안정성·손가락·발 지지·복원 동작 검증이 아니다.**

승인 학교 배경에 해당 공간과 지지 면이 없다면 `BLOCKED_LAYOUT`다. 새 벽이나 장치를 몰래 추가하지 않는다. 실제 판의 낙하 부피, 귀뚜라미의 안전 공간 진입과 탈출, 피노키오의 양손 접촉, 기존 받침으로 되돌리는 접촉점 전환을 애니매틱에서 확인해야 한다.

C13의 옆 탈출은 ‘판 중앙 밑으로 새로 진입하거나 정면으로 통과하지 않고 가장 가까운 열린 측면으로 빠져나오기’로 구체화했다. ‘판의 투영 아래를 어느 순간에도 지나지 않는다’는 별도의 절대 조건까지 만족했다고 주장하지 않는다.

근거: `assets/S12_RESCUE_LAYOUT_V2.md/json`, `assets/S12_SPRITE_AND_MOTION_SPEC.md`, C06~C14, `evidence/RESCUE_ABSTRACT_FIXTURE_RECHECK_V2.json`.

## 계획 시간과 제작 기준

V1의 446초에서 V2는 468초 계획으로 조정했다. 추가된 시범·동작 분리와 대사별 시간 예산을 반영한 작성 단계 수치다. 실제 음원·움직임을 느리게 늘린 결과가 아니며, 최종 영상 길이를 측정한 것도 아니다. 본편 최소 360초는 유지하되 기다림과 모델 시간을 본편 분량에 합산하지 않는다.

작성 예산의 110wpm은 합성 엔진의 일괄 속도 명령이 아니다. 실제 연기 음원과 동작 완료를 우선하고, 발음을 자르거나 속도를 올려 예정 컷에 맞추지 않는다. 정밀 음소 립싱크 신규 구현을 이번 수정의 조건으로 추가하지 않고 기존 말하기 입모양 시작·종료와 표정·시선·몸짓을 최종 음원에 맞춘다.
