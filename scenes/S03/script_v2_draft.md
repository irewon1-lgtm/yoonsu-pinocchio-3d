## S02 베이스 엔진과의 일치 / 재사용 계약

1. **그대로 재사용:** S02의 `scene_design_v2.json` 기본 필드(`scene`, `version`, `designer`, `stage`, `duration_target_seconds`, `wait_excluded`, `original_dialogue_count`, `new_dialogue_count`, `target_fps`, `scenes`), 비트마다 `id/title/start_seconds/end_seconds/goal/continuity/dialogue/shots/interaction_id`, 영어 문장 `kind/speaker/text`, 컷 `id/start_seconds/end_seconds/camera/acting` 구조. S02 문서와 코드 파일은 건드리지 않는다.
2. **공통 플레이어 상태 계약(구현 전):** `PLAYING → PROMPT_AUDIO → WAITING_FOR_RESPONSE → REACT_ONCE → RESUME → PLAYING`. 말의 내용은 확인하지 않고 VAD나 보호자 터치로 진행. 질문 오디오가 끝나야 입력 활성, 힌트는 대사 재생 중 마이크 OFF, 반복 소리로 이중 실행 금지. 타임라인은 WAIT 동안 멈춤.
3. **기본 3D 연기 캐시:** S02 손가락/눈동자·고개·기본 보행·제페토 손 접촉·수줍은 미소·입모양/감정·24fps 카메라를 같은 rig/animation layer에서 재사용. 실물 캐시의 존재 확인 전에는 `NOT_RUN`. S03에서 새로 필요한 것은 **책장 넘기기, 블록 잡기/쌓기, 머리 만지기, 슬라이드 서랍, 책 들기, 허리 굽혀 모자 집기, 모자 방향 회전/착용, 가방 플랩·매듭**.
4. **캐릭터/배경 잠금:** S01의 승인 외형 및 S02 아침 작업실 조명·캐릭터 비율/크기/목재 질감 유지. 피노키오는 끝까지 목각. 장면 종료까지 빨간 모자를 머리에 쓰고 가방에 책을 넣어 끈을 묶는다.
5. **성우 재사용:** `assets/voice_refs/v6/VOICE_REFERENCES.json`, `assets/voice_refs/v6/{geppetto,pinocchio,narrator}_V6_APPROVED.mp3`, `downloads/s01-complete/S01_V7_VOICES.zip` 참고. Chatterbox Nano는 참조/생성 설정만 확인된 상태; 실제 같은 음색 청감 승인 전 새 음원을 최종판으로 배포 금지. 피노키오·제페토·내레이터 외 다른 대사 캐릭터 추가 금지.
6. **아동 친화:** 영어 이해나 정확한 발화 전제 없음. 행동 먼저 보여주기→영어 짧게 제시→윤수 소리/보호자 터치→행동으로 결과 확인. I03 `Under the chair!`, I04 `Put it on!`은 원본 그대로 보존.
7. **실물 3D QA:** 의자 아래 모자의 붉은 끝은 I03 이전 계속 존재하며 응답 직전까지 위치 고정; I03 이후 의자 아래 비어야 함. 모자가 I04 이전에는 착용되지 않고 I04 이후에는 벗지 않음. 책은 B01/B05에서 탁자→제자리, B09에서 가방으로 1회만 이동, B10 끈 묶음 완료. 인물이 소품 관통·비정상 스케일·순간 이동·발 미끄러짐을 일으키면 FAIL.
8. **현실적 분량:** 456초 목표를 10개 비트·50개 서로 다른 실제 동작 컷으로 배정했으며 반복 재생·무의미한 정지로 대체 불가. 최종 MP4 ffprobe와 컷별 오디오 길이 합계가 ≥360초인지 다시 실측.
9. **게이트:** 본 파일은 제가 작성한 G1 설계이고 `REVIEW_REQUIRED`; Codex가 상세 설계를 다시 쓰는 것이 아니라 승인 뒤 G2–G6 구현한다. 현재 S02 실제 3D 엔진은 미확인이라 `ENGINE_NOT_VERIFIED` 상태.
