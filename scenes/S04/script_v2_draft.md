## 4. S02→S03→S04 기술·교육 계승 계약

1. **JSON 데이터 스키마:** S02 `scene_design_v2.json`과 동일한 필수 필드, 10개 beat에 5컷씩, 영어 대사의 `kind/speaker/text` 및 ORIGINAL `source_index`, 인터랙션 `id`. 3화와 동일한 보조 메타데이터 사용. 4화의 리그/카메라 실물은 이전 화 구현의 재사용 확인 전까지 NOT_RUN.
2. **실행 상태 기계:** `PLAYING → PROMPT_AUDIO → WAITING_RESPONSE → REACT_ONCE → RESUME`만 허용. 질문 음성 끝나기 전 VAD 잠금, 5초 무응답 시 천천히 예시 음성, 마이크 권한 거부나 소음 환경에서 보호자 터치 대안, 재발화/버튼 중복 1회 반응 보장.
3. **행동부터 영어:** 단어를 몰라도 화면 동작 시범을 먼저 보여준다. 정확한 영어 문장 인식·채점은 하지 않는다. 아이가 아무 말이나 해도 반응으로 이야기가 앞으로 진행되며 직접 터치로도 완주 가능.
4. **3D 애니메이션:** 보행은 발바닥 접지와 골반·무릎·팔 반대 위상을 갖도록, 귀뚜라미는 나뭇잎→지면 점프에 실제 곡선/중력 사용, 표지판은 고정 좌표와 지형 연속성 유지, 개구리는 원본의 '물웅덩이 옆'에서만 작은 점프, I07은 실제 마른 땅 건너 착지. 캐릭터가 정지 이미지처럼 떠다니거나 액션 전후 순간이동하면 FAIL.
5. **장면 경계:** S03 종료 모자 착용+가방 결속→S04 대문 닫힘→I05 이후 개방→꽃길→두 갈래길→I06 학교 길→웅덩이→I07 점프→학교 방향 계속→마지막 '정체 모를 소리'는 S05로 연결.
6. **성우 관리:** 제페토/피노키오/내레이터는 `assets/voice_refs/v6/` 기준 MP3와 S01 V7 최종 MP3를 활용하여 같은 목소리 후보로 합성. **귀뚜라미 새 캐릭터 성우는 사용자 승인 전 잠금**. 승인 성우를 제페토·피노키오에서 귀뚜라미로 돌려쓰지 말 것. 임의 성우를 최종 기본값으로 적용 금지.
7. **정직한 완료 기준:** 본 자료는 전체 스토리와 연기 상세 설계 G1의 PASS 후보이며 사용자 검토 전 `REVIEW_REQUIRED`. 479초는 설계 목표. 실제 MP4 최소 360초, 50컷 실제 움직임, 10회 상호작용, 음성 일관성은 제작 후 별도 검증.
8. **업무 분리:** 창작/연출은 ChatGPT가 책임지고 Codex가 스토리를 새로 쓰거나 추가 대사를 임의로 대체하지 않는다. 배우 리그·음성 소스 접근 결손은 `BLOCKED_RESOURCE`로 보고하되 S01-S03 원본을 덮어쓰지 않는다.
