# 윤수 피노키오 S01 · 할아버지의 작은 작업실

영화관처럼 보려면 S01_COMPLETE_MOVIE_1080P.mp4를 연다. 영어 자막과 승인 음성이 들어 있으며 1분 49.25초 동안 아침 장면까지 이어진다.

함께 참여하려면 S01_COMPLETE_OFFLINE_PLAYER.html을 내려받아 동영상과 JavaScript를 지원하는 브라우저로 연다. 모든 장면·음향과 영어 음성이 이 한 파일에 들어 있다. ‘재생’을 누르면 시작한다. 선택 참여는 잠시 기다리면 넘어간다. C06의 “He is moving!”에서는 ‘마이크로 참여’ 또는 ‘직접 응답하고 계속하기’를 누른다. 기기의 파일 미리보기에서 버튼이 반응하지 않으면 브라우저에서 연다.

TIMELINE.json과 subtitles.en.srt에는 발화별 시작·끝과 원문이 있다. VOICE_LOCK.tsv는 원본 26개와 SHA를 대조한다. BEATS_54_CONTACT.jpg는 배포 MP4에서 뽑은 54개 비트의 실제 화면이다. SCREENING_KO.md에는 컷별 화면 검토와 검증 범위가 있다. 편집 가능한 Blender 프로젝트와 원본 음성 묶음은 같은 GitHub 다운로드 폴더에 별도로 제공한다.
