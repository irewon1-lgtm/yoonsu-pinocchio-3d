# D1 정지 화면 검증

D1 사용자 시각 판정은 REVIEW_REQUIRED다. 원본과 최종 .blend를 각각 다시 열어 같은 자세의 피노키오 좌표를 대조했다. 아래의 의자 가림률은 프레임에 들어온 제페토의 불투명 ID 픽셀 가운데 의자 마스크가 덮은 비율이다. 인물 전체에서 카메라가 잘라 낸 면적은 분모에서 제외했다.

| 컷 | 카메라 회전 | 제페토 얼굴 폭 × 높이 | 피노키오 얼굴 폭 × 높이 | 의자 가림 | 접촉점 |
|---|---:|---:|---:|---:|---:|
| C06_A | 0° | 198 × 273 px | 134 × 131 px | 0% | 3개 프레임 안 |
| C06_B | 8° | 250 × 320 px | 157 × 152 px | 0% | 3개 프레임 안 |
| C07_A | 0° | 179 × 244 px | 106 × 117 px | 0% | 2개 프레임 안 |
| C07_B | 8° | 213 × 283 px | 120 × 135 px | 0% | 2개 프레임 안 |
| C07_JOY | 8° | 205 × 290 px | 120 × 135 px | 0% | 2개 프레임 안 |

얼굴의 크기는 1280 × 720에서 평가된 머리 피부 메시 투영 경계다. 미소·놀람·기쁨의 차이는 그림에서 검토한다.

| 검사 | 판정 | 증거 |
|---|---|---|
| 승인 원본 | PASS | 기존 검토 ZIP, 내부 67개 파일, D0 원장 35건의 SHA-256 대조. SOURCE_AUDIT.json |
| 원본 배경 | PASS | 재개방 후 내장 PNG의 SHA-256이 18ebc03242c327d2f262a7e6dfa945917d8ca499abe3233af50b547592cbb1fa와 일치. SCENE_READBACK.json |
| C06·C07 월드 좌표 | PASS | 같은 컷에서 피노키오 모든 평가 정점의 세계 좌표 해시, 피노키오·제페토 인스턴스 행렬이 이전 레이아웃과 일치. 다른 구도에서도 지지점 세계 좌표 일치. FINAL_CONTACT.json |
| 실제 받침 표면 | PASS | C06의 머리·등·아래 다리 근접점에서 아래 방향으로 쏜 광선이 실제 접힌 천에 닿음. 간격은 0.00050 BU. C07의 양쪽 밑창 표본과 천의 수직 간격은 0.000001 BU 미만. 접촉 표본은 프레임 안에 있음. |
| 창작 카메라와 배경 | PASS | 상판 위 기준 위치를 원본 그림으로 역투영해 비교. SHOT_PLATE_REGISTRATION.json에 픽셀 오차 기록. 뒷벽·측면 가구는 승인 그림을 사용한 2.5D 해석. |
| 프레임·의자 가림 | PASS | 원래 전경에서 제페토 가림 약 25%. 새 다섯 구도에서 두 캐릭터의 의자 가림 0%. SHOT_VISIBLE_ID.json |
| 시선 단서 | 측정 | 각 눈의 흰자 중심에서 동공 중심으로 향하는 화면 벡터는 다섯 장면 모두 피노키오 쪽 반평면을 향함. GAZE_PROJECTION.json. 실제 양안 주시 정밀도와 감정의 설득력은 별도 시각 판단. |
| 렌더·편집 파일 | PASS | 다섯 장면을 Blender 4.3.2에서 다시 열었다. 관절 리그·시간 액션·외부 .blend 라이브러리 0. 새 장면은 Cycles CPU, 1280 × 720, 최대 40 samples. |
| 최종 놀람 연기 수정 | PASS | 얼굴 방향을 바꾼 C07 A·B를 다시 렌더했다. 나머지 세 화면은 인물·카메라·광원·배경을 대조해 동일한 렌더를 사용했다. FINAL_FRAME_REUSE.json과 렌더 서명 및 로그. |
| 체중 이동 과정·동적 미끄럼·리깅·기상 애니메이션 | NOT_RUN | 제출물은 다섯 정지 장면. D2 및 D3 진입 전. |
| 얼굴 동일성·장면 구도·감정 전달 | REVIEW_REQUIRED | 사용자의 D1 시각 검수 대기. |
