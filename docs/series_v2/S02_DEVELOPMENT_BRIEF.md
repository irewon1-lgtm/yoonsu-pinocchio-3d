# S02 G0–G1 작업 브리프: 피노키오의 첫 친구
**현재:** 확장 대본 미작성/미승인. 아래는 6분+ 제작 설계 초안이다.

## 유지할 이야기
V1.1 S02의 **아침 기상 → 손가락/발가락 관찰 → 첫걸음/쿠션 위 넘어짐 → 제페토의 위로 → '이곳이 집인가요?' → 윤수 소개 → 부끄러워 숨기 → 윤수의 인사 → 첫 친구의 기쁨** 순서를 지킨다. 원본 영어 대사는 문구·의미·선후를 그대로 보존한다. 글로벌 `I02` ("Hello, little Pinocchio!")는 총 10회 중 1회로 계산한다.

## 6분 30초 목표 타임라인(아이 대기 시간 제외; 신규 내용 검토 전 초안)
| 구간 | 서사 시간 | 내용 | 잠정 참여 |
|---|---:|---|---:|
| B01 | 00:00–01:00 (60초) | 아침 작업실, 놀란 눈빛, 손·발을 알아봄 | 2 |
| B02 | 01:00–02:00 (60초) | 서기·균형·의지할 곳 찾기 | 2 |
| B03 | 02:00–03:10 (70초) | 첫걸음→미끄러짐→쿠션 위로 넘어짐 | 2 |
| B04 | 03:10–04:15 (65초) | 제페토 위로, 다시 일어나 움직임 탐색 | 1 |
| B05 | 04:15–05:20 (65초) | 집과 주변 물건 탐색, '친구' 등장 준비 | 1 |
| B06 | 05:20–06:30 (70초) | 제페토 뒤 숨기→윤수 바라보기→인사→미소 | 2 |
| **합계** | **390초 목표** | **최소 360초에 30초 여유** | **10회** |

- 신규 참여 9개 + 기존 `I02` 1개 = 10개. 신규 참여 ID는 `S02-P01`~`S02-P09`; 기존 `I02`는 마지막 인사 구간에 유지. 실제 발생 위치와 문장은 상세 대본 G1에서 확정.
- 아이가 영어를 이해해야 수행되는 퀴즈보다 손·발·균형·쿠션·인사 등 **보이는 행동에 연결**한 참여를 우선.
- 모든 이벤트: 원인/질문 종료 → WAIT 시각 상태 → 아이 소리 또는 보호자 터치 → 1회 REACT 애니메이션 → 후속 대사. 10회가 이야기 진행을 방해하지 않아야 한다.

## S02 3D 난도 핵심
1. 손가락 개별 굽힘, 눈과 시선이 움직이는 손을 따라감.
2. 처음 서기/걷기의 준비 동작, 중심·무릎·발바닥 접지 일치.
3. 쿠션 위 넘어짐에서 넘어지기 전 균형 상실, 물리적 착지/접촉, 팔·다리 복귀.
4. 제페토와 피노키오의 일관된 거리/크기, 시선 교환, 위로하는 손짓.
5. 부끄러워 몸 숨기기, 제페토 뒤에서 얼굴 내밀기, 카메라 향해 첫 손 흔들기.
