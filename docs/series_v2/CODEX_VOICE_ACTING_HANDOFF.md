# Codex 실행 지시 — 3·4·5화 수정 대본과 캐릭터 음성 연기

## 목표와 현재 완료 범위

사용자는 검토 지적 수정과 함께, 책을 읽는 듯한 평평한 합성 대신 **상대의 말을 듣고 상황에 반응하며 이야기하는 캐릭터 음성**을 만들 수 있도록 모든 대사의 연기 지시를 요청했다.

저장소에는 수정 대본과 문장별 음성 제작표가 있다. 이 문서는 그 자료를 실제 음성으로 구현할 실행 지시다. **이번 문서 작성 단계에서 실제 WAV 합성·청취·립싱크·영상 제작은 하지 않았다.**

1·2화는 사용자가 완료했다고 지정했다. 본편·음원·검사기·기존 자산을 수정하거나 다시 만들지 않는다. 정본 대본 두 파일과 승인 성우 MP3 네 개도 보존한다.

## 1. 읽을 파일과 정본

1. `AGENTS.md`의 현재 V2.1 범위.
2. `docs/series_v2/VOICE_PERFORMANCE_BIBLE_V2_1.md`와 같은 이름의 JSON: 발화 캐릭터7명의 음색·연기 기준.
3. `scenes/S03`, `S04`, `S05` 각각의 `script_v2_draft.md`, `scene_design_v2.json`, `interaction_map_v2.json`.
4. 각 화 `voice_direction_plan.json` 또는 `voice_direction_sheet.csv`: 본편·모델 예시의 고유 ID, 정확한 영어, 화자, 고정 참조, 의도·감정·말투·속도·강세·쉼, 전후 문맥.
5. `docs/series_v2/STORY_CONTINUITY_S01_S12.json`: 소품·장소·소리·목적·다음 화 인계.

**현재 정본은 JSON의 영어 대사와 그 줄의 `voice_direction`이다.** 이전 리뷰의 수정 전 예시를 합성하지 않는다. 읽기용 대본·CSV·작업표는 같은 JSON에서 생성된다. 서로 다르면 합성 전에 동기화한다.

## 3. 책 읽는 음성을 막는 입력 방식

|필드|용도|실제 발화|
|---|---|---|
|`spoken_text`|원본 또는 수정 확정 영어 문장|**이 필드만 읽음**|
|`approved_reference`|동일 캐릭터 음색 참조·SHA|참조 오디오로만 사용|
|`instruct_prompt_en`|캐릭터 기준+해당 문장의 영어 연기 지시|읽지 않음|
|`voice_direction`|상대·목적·감정·강세·쉼·속도|지원되는 연기 제어에 매핑|
|`context_before_do_not_speak`, `context_after_do_not_speak`|상대의 이전 말과 다음 반응|문맥으로만 사용; 출력 금지|
|`suggested_output`|대사 ID로 고정한 WAV 경로|파일 이름으로만 사용|

### 현재 호출에서 바꿔야 할 점

이전 S03/S04 호출은 `model.generate(text, audio_prompt_path=...)` 형태로 대사와 참조만 전달했다. 그 호출에는 문장별 연기를 전달하는 코드가 없었다. 그대로 반복하고 감정이 적용됐다고 보고하지 않는다.

1. 실제 설치 엔진의 버전·API·소스를 확인한다. 자연어 연기 지시, 스타일·감정 제어, 문맥 입력 중 실제 지원하는 기능을 확인한다.
2. 지원하는 기능에만 `instruct_prompt_en`과 줄별 속도·쉼·강세를 전달하는 어댑터를 구현한다. 지원하지 않는 `instructions`, `emotion`, SSML 인수를 지어내지 않는다.
3. 자연어 지시를 직접 지원하지 않으면 실제 지원되는 스타일 제어 또는 동일 승인 화자의 적절한 연기 참조를 쓸 수 있는지 확인한다. 음색을 유지할 수 없으면 한계를 기록한다. 새 엔진·새 성우를 승인받은 것처럼 바꾸지 않는다.
4. 지시를 대사 앞에 붙여 읽게 하거나, 지시를 버린 중립 합성으로 조용히 대체하지 않는다.
5. 무작정 대량 생성하지 말고 대표 문장으로 제어가 반영되는지 먼저 확인한다.

옛 `--synthesize` 경로는 지시를 무시하는 합성을 막기 위해 `DIRECTED_ADAPTER_REQUIRED`와 종료 코드2를 반환한다. 기본 검사·작업표 내보내기는 사용 가능하다. **가드나 연기 지시를 삭제해 회피하지 말고, 엔진의 실제 지원 기능에 어댑터를 연결한다.**

## 4. 문장별 연기의 핵심

- 피노키오의 “School?”은 처음 들은 말의 뜻을 이해하려는 짧은 되물음이다. “I will, Grandpa!”에서는 놀이 리듬을 잠깐 멈추고 진심을 보여준다.
- 제페토의 “You're still learning.”은 실패 지적이 아니라 안심시키는 반응이다. “Go to school and come home before supper.”는 기대와 걱정을 한 생각씩 전달한다.
- 귀뚜라미의 “Pinocchio, remember your promise.”는 이름에서 시선을 잡고 다정하게 걱정한다. 큰 소리로 혼내지 않는다.
- 내레이션의 “one little minute”와 “a very long time”은 차이를 부드럽게 들려준다. 무서운 예고편 톤 금지.
- 문장마다 같은 시작 높이·하강조·쉼을 반복하지 않는다. 느낌표를 모두 고함으로, 질문을 모두 같은 상승조로 처리하지 않는다.
- 미소를 원문에 없는 웃음·감탄사·이름으로 대체하지 않는다. 표정은 음색과 호흡의 작은 변화로 표현한다.
- 실제 WAV가 길면 컷을 조정한다. 음성을 과속·피치 변경으로 우겨 넣거나 긴 무음·대기로 6분을 채우지 않는다.
- 전후 쉼은 합성 파일의 기존 무음을 측정·정리한 뒤 타임라인에서 한 번만 적용한다. 엔진이 이미 넣은 쉼에 같은 길이를 다시 더하지 않는다. 문장 내부 쉼도 엔진 또는 편집 중 한 곳에서만 적용하고 처리 위치를 기록한다.

## 6. 윤수 모델 예시와 입력

본편310줄과 별도로 참여30개의 예시 파일을 만든다. 실제 입력과 개수는 각 화 작업표에서 확인한다.

1. 본편의 마지막 질문 오디오가 끝난다.
2. 본편 시계를 멈추고 해당 `-EXAMPLE`을 한 번 들려준다. 질문한 캐릭터의 고정 음색으로 세 단어를 자연스럽게 이어 말한다.
3. 예시 중 마이크를 끄고 끝난 뒤 VAD를 연다. 예시가 스스로 입력으로 잡혀 반응하면 실패다.
4. 정확한 단어·발음 채점 금지. 보호자 터치는 예시를 건너뛰고 진행할 수 있다.
5. 입력 뒤 반응 동작을 한 번 끝낸 후 지정된 첫 재개 대사로 돌아간다.

예시는 본편 밖의 학습 안내다. 본편 대사 수·시간에 넣거나 등장인물이 이미 답을 알아낸 이야기 사건으로 취급하지 않는다. 무응답5초 뒤 다시 듣기/터치를 제시한다.

## 7. 준비·검사 명령

저장소 루트에서 실행한다. S01/S02 검사·렌더·음성 생성은 실행하지 않는다.

```bash
python3 scripts/voice_direction_tools.py validate --scenes S03 S04 S05
python3 scripts/s03_approved_voice_tts.py --export-jobs /tmp/S03_voice_jobs.json
python3 scripts/s04_approved_voice_tts.py --export-jobs /tmp/S04_voice_jobs.json
python3 scripts/s05_voice_preflight.py --export-jobs /tmp/S05_voice_jobs.json
```

승인 범위에서 JSON을 수정했다면 `python3 scripts/voice_direction_tools.py build --scenes S03 S04 S05`로 대본·작업표·CSV를 동기화한다. 원본 변경·잘못된 캐릭터·발화 예산 초과·본편 WAIT 포함은 통과시키지 않는다.

위 명령은 음성을 합성하지 않는다. 준비 검사와 내보내기를 실제 오디오 제작 PASS로 보고하지 않는다.

## 8. 합성 후 제출할 결과와 판정

- 대사 ID별 WAV, 캐릭터·화·원본/신규/모델 구분을 유지한 재생 목록.
- 엔진·모델 버전/리비전·시드(지원 시)·참조 SHA·실제 지원 제어와 전달값의 `voice_generation_manifest.json`.
- 파일별 정확한 문구, 참조 음색 일치, 줄별 감정·의도, 명료도, 실제 길이, 청취 판정의 `voice_performance_QA.json`.
- 질문 종료·예시 종료·입력 개방·반응 시작·재개 발화의 실제 연결. 립싱크와 접촉이 겹치는 컷은 영상으로 확인.
- 누락·무음·깨짐·지시문 낭독·화자 혼용·원문 누락·평평한 낭독은 해당 줄만 수정하고 재확인. 적합한 전체 화를 불필요하게 재생성하지 않는다.

**완료는 실제 오디오와 청취 증거로 판정한다.** 파일 수·WAV 길이·지시 존재만으로 연기 PASS를 주지 않는다. 미확보 캐스트와 미실행 항목을 정확히 구분한다.
