S02 `scene_design_v2.json`의 기본 필드와 비트/컷 구조를 유지한다. S05에는 발화별 ID와 컷 배정, 외부 WAIT 경계를 더했다. 이는 **데이터 계약의 확장**이며, 실제 S02 Blender 엔진이나 플레이어가 이 자료를 이미 읽고 실행한다는 증거가 아니다. 기존 S01~S04의 파일을 수정하거나 S05 설계를 임의로 줄이지 않는다.

| 경계 | 인계하는 상태 | 반드시 남겨야 할 다음 사건 |

| S05→S11 | 같은 학교 길, 같은 음악과 천막을 기억할 수 있도록 소리/공간 단서를 보존 | 다음 날에는 같은 유혹 앞에서 학교를 선택하며, 공연 자체를 나쁜 것으로 규정하지 않음 |

S05 끝의 북소리와 광장 환경음은 S06 첫 컷까지 자연스럽게 이어지는 계획이다. 이어보기에서는 중간 엔딩 카드·다음 화 예고·앞 장면의 재소개·불필요한 암전을 넣지 않는다. 개별 장면 재시작이 필요하면 비서사 UI에서 처리하고 본편 시간을 늘리지 않는다.

## 본편 시계와 입력 처리

1. 각 비트 C01~C03에서 사건과 짧은 시범·질문이 재생된다. 질문의 실제 음성 종료 이벤트와 C03 종료가 모두 확인되어야 입력을 연다. 표의 초는 설계값이므로 합성 후 실제 음성에 맞춰 재검증한다.
2. C03/C04 경계에서 본편 시계를 정지한다. 이 WAIT의 눈 깜박임·호흡·무반응 시간은 432초에 넣지 않는다. 미리 C04 핵심 반응을 재생하지 않는다.
3. 발화 활동 후 약 1초의 조용한 구간 또는 보호자 터치로 동일한 이벤트를 한 번만 해제한다. 단어 인식·발음 채점·정답 평가를 하지 않는다.
4. 약 5초 무반응이면 예시를 재생할 수 있다. 예시 중 마이크 판정을 끄고, 예시·재시도·다시 듣기도 본편 시계 밖에서 처리한다. 재시도는 참여 횟수를 늘리지 않는다.
5. 한 번 해제된 이벤트는 재생 중 VAD/터치로 중복 실행되지 않는다. C04의 반응을 마친 뒤 지정 대사를 재개하고, 자동 본편 진행으로 돌아온다.

완성 영상은 실제로 WAIT·반복을 제외한 본편이 360초 이상인지 에디트 목록과 `ffprobe`로 검증한다. 432초의 JSON이나 10,368프레임 계획만으로 영상 길이 PASS를 선언하지 않는다. 대사 밀도 추정 검사도 실제 영어 음성의 길이·쉼·연기 리듬 검사를 대체하지 않는다.

## 음성과 소품

- 내레이션 A, 피노키오 A는 기존 승인 참조 파일을 유지한다. 제페토 A·파란 요정 C의 참조 파일도 변경 없이 검증한다.
- 귀뚜라미는 승인 음성이 없어 `BLOCKED_RESOURCE`. 본편 대사와 선택적 예시 모두 같은 결손을 명시하며 다른 캐릭터의 목소리를 복사하지 않는다.
- `s05_voice_preflight.py`는 참조 MP3 SHA와 실제 대본/예시의 성우 배정만 확인한다. 기본 종료 코드 0을 전체 음성 제작 완료로 해석하지 않는다. `--require-ready`는 결손이 남으면 종료 코드 2다.
- S05에서는 책을 펼치거나 꺼내어 읽지 않는다. 가방을 만지고 몸 앞으로 옮겨도 같은 책이 안에 남는다. 모자·신발·코·가방의 위치 변화는 실제 동작으로 보여 준다.
- 낮은 가지·관객 통과·가방 이동·한 발 물러남은 발 접지와 손 접촉이 있는 실제 3D 동작으로 구현한다. 정지 그림이나 반복 동작으로 계획 시간을 채우지 않는다.
