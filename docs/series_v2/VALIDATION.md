# S03~S05 수정 대본·음성 연기 지시 검증

## 현재 범위와 판정

**현재 범위는 S03·S04·S05의 검토 지적 수정, 본편 310개 발화와 모델 예시 30개에 대한 음성 연기 지시 및 작업표 내보내기다.** S01·S02는 `USER_COMPLETED_PRESERVED`이며 이번 작업에서 두 완료본의 제작 검사·렌더·음성 생성을 다시 실행하지 않는다. 원본 소스와 보존 범위를 확인하는 자료 검사는 완료본을 재심사한 결과로 해석하지 않는다.

2026-11-23에 실행한 결과는 [VOICE_DIRECTION_VALIDATION_2026-11-23.json](VOICE_DIRECTION_VALIDATION_2026-11-23.json), 각 장면의 `voice_preflight_report.json` 및 [수정·음성 설계 보고서](S03_S05_CORRECTION_AND_VOICE_REPORT.md)에서 확인한다. 최신 구현 안내는 [CODEX_VOICE_ACTING_HANDOFF.md](CODEX_VOICE_ACTING_HANDOFF.md)다.

| 장면 | 원본 / 신규 발화 | 본편 연기 지시 | 예시 연기 지시 | 본편 계획 시간 |
|---|---:|---:|---:|---:|
| S03 | 22 / 92 | 114개 | 10개 | 598초 · 9분 58초 |
| S04 | 32 / 77 | 109개 | 10개 | 527초 · 8분 47초 |
| S05 | 18 / 69 | 87개 | 10개 | 472초 · 7분 52초 |
| **합계** | **72 / 238** | **310개** | **30개** | **각 장면의 계획값** |

각 장면은 10비트·50컷·참여 10회다. 시간은 문장별 계획 말속도와 전후·내부 쉼, 실제 행동 선행·후행 시간을 배정한 **`PLANNED_NOT_MEASURED`** 값이다. WAIT·예시·반복은 본편 시간에 포함하지 않는다. 설계 검사 결과는 **`DIRECTED_DESIGN_PASS_ONLY`**이며 실제 음성 합성·청감·립싱크·MP4 길이·장치 동작은 **`NOT_RUN`**이다.

| 음성 준비 및 내보내기 | 승인 참조 SHA와 줄별 작업표에 지시가 포함됨, 본편 310개·첫 예시 30개 분리 | 실제 엔진에 연기 지시가 전달되어 적용됐다는 결과 |
| 차단 경로 | 미승인 귀뚜라미의 준비 완료 요구 및 지시를 무시하는 옛 합성이 예상대로 종료 코드 2 반환 | 미확보 성우나 실제 합성의 완료 |

설계 검사에는 **8개 잘못된 입력을 거부하는 반례 검사**도 포함했다. 문장별 지시 누락, 잘못된 캐릭터 프로필, 원문에 연기 지시 혼입, 본편 WAIT, 컷 음성 예산 초과, 네 단어 cue, 첫 예시 전에 마이크 개방, 귀뚜라미의 인사 후 최초 착지를 각각 거부했다. 연결 검사도 경계 누락·순서 변경·조기 커튼 개방·잘못된 첫 대사를 거부했다. 이는 구조화된 계약의 검사이며 모든 연출의 자연스러움을 자동 판정한 것은 아니다.

## 현재 검사와 작업표 내보내기 명령

저장소 루트에서 필요한 변경 범위에 한해 실행한다. 아래는 S03~S05 경로이며 S01·S02 제작 검사는 포함하지 않는다.

```bash
python3 scripts/voice_direction_tools.py validate --scenes S03 S04 S05
python3 scripts/voice_direction_tools.py self-test --scenes S03 S04 S05 --report docs/series_v2/VOICE_DIRECTION_VALIDATION_2026-11-23.json
python3 scripts/validate_story_continuity.py --self-test
```

`validate_s03_design.py`, `validate_s04_design.py`, `validate_s05_design.py`의 장면별 진입점도 현재 문장별 설계 검사에 연결된다. 고정된 옛 분량이나 단일 wpm 상한만 검사하던 과거 결과를 최신 음성 예산 검사 대신 사용하지 않는다.

```bash
python3 scripts/s03_approved_voice_tts.py --export-jobs /tmp/S03_voice_jobs.json
python3 scripts/s04_approved_voice_tts.py --export-jobs /tmp/S04_voice_jobs.json
python3 scripts/s05_voice_preflight.py --export-jobs /tmp/S05_voice_jobs.json
```

이 명령은 참조·배정 검사와 작업표 내보내기만 수행하며 WAV를 생성하지 않는다. 결과의 `direction_export_integrity: PASS`는 지시가 작업표에 실렸다는 뜻이다. `direction_adapter_application`, 합성·실제 길이·립싱크·청감 검토는 계속 `NOT_RUN`이다.

승인 범위의 JSON을 변경했다면 `python3 scripts/voice_direction_tools.py build --scenes S03 S04 S05`로 읽기용 대본·작업표·CSV를 동기화한다. 실제로 변경되지 않은 완료본이나 이미 유효한 검사까지 반복하지 않는다.

## 성우 준비와 차단 상태

[전체 캐릭터 기준](VOICE_PERFORMANCE_BIBLE_V2_1.md)은 7명의 발화 캐릭터를 다룬다. 피노키오·제페토·내레이션·파란 요정은 기존 승인 참조 4개를 잠근 상태다. 귀뚜라미·마라·핍은 연기 프로필이 작성되었으나 승인 음색 참조가 없는 3명이다. 현재 S03~S05 중 귀뚜라미가 실제로 필요한 S04·S05의 해당 성우 자원은 `BLOCKED_RESOURCE`다.

| 실행 경로 | 현재 예상 결과 | 의미 |
|---|---|---|
| S03 기본 음성 준비·내보내기 | 종료 코드 0, `REFERENCE_READY_AUDIO_NOT_RUN` | 필요한 기존 참조와 작업표 준비. 새 음성 제작 완료가 아님. |
| S04·S05 기본 음성 준비·내보내기 | 종료 코드 0, 귀뚜라미 `BLOCKED_RESOURCE` 명시 | 자료 검사·내보내기는 성공하지만 전체 캐스트 준비는 미완료. |
| `python3 scripts/s05_voice_preflight.py --require-ready` | **종료 코드 2** | 미승인 귀뚜라미 때문에 전체 준비 완료 요구를 거부. |
| `python3 scripts/s03_approved_voice_tts.py --synthesize --limit 1` 등 옛 합성 경로 | **종료 코드 2**, `DIRECTED_ADAPTER_REQUIRED` | 줄별 지시가 누락되는 합성을 차단하며 오디오를 생성하지 않음. |

**실제 설치 엔진의 지원 기능에 연기 지시를 전달하는 어댑터는 아직 구현되지 않았다.** 이전 `generate(text, audio_prompt_path=...)` 경로는 캐릭터 참조와 대사만 넘겼으며 줄별 연기를 전달하지 않았다. 차단을 제거하거나 지원되지 않는 인수를 지어내지 말고, [실행 인계](CODEX_VOICE_ACTING_HANDOFF.md)에 따라 실제 지원 제어에 연결한 뒤 대표 문장의 청감과 음색 유지부터 확인한다.

## 첫 모델 예시와 본편 시계

30개 참여의 **첫 예시는 기본 경로에 포함**된다. 선택적인 것은 무응답 뒤 다시 듣기이며, 보호자 터치는 첫 예시를 건너뛰고 반응을 진행할 수 있다.

1. 마지막 질문 음성이 끝나는 C03 경계에서 본편 시계를 멈춘다.
2. 본편 밖에서 해당 화자의 세 단어 `-EXAMPLE`을 한 번 재생한다. 예시 중 마이크 판정은 꺼 둔다.
3. 예시가 끝난 뒤 VAD 또는 보호자 터치를 받는다. 무응답 5초 뒤 다시 듣기·터치 선택을 제시한다.
4. 반응 동작을 한 번 완료한 뒤 C04의 지정된 첫 대사로 재개한다.

예시 음성이 아동의 입력으로 감지되거나 인물의 지식·소품 상태·발견 시점을 먼저 바꾸면 실패다. 단어 내용 인식·발음 채점은 하지 않으며, 예시·대기·반복을 본편 분량이나 본편 310개 발화에 더하지 않는다.

## 실제 제작 후 별도로 필요한 증거

- 대사 ID별 WAV와 실제 엔진·모델·지원 제어·참조 SHA를 기록한 생성 manifest.
- 정확한 문구, 화자 정체성, 문장별 의도·감정·명료도를 확인한 실제 청취 결과.
- 실제 음성 길이와 쉼을 한 번씩 반영한 컷 타이밍, 립싱크·표정·접지·소품 접촉 영상.
- 질문 종료·예시 종료·입력 개방·반응·재개의 실제 플레이어/기기 검증.
- 각 장면의 대기·예시·반복을 제외한 실제 본편 ≥360초와 경계의 소리·상태 비교.

이 증거가 아직 없으므로 문서 정합성이나 작업표 내보내기의 PASS를 실제 음성·영상·연기 PASS로 확대하지 않는다.

## 역사적 검증 자료의 적용 범위

초기 V2 단계에서는 `validate_series_v2.py`와 `validate_s02_design.py`를 조합해 S02 설계 및 당시 정책을 확인했다. **이것은 과거 작업 기록이며 현재 S02 제작을 다시 시작하는 절차가 아니다.** 현재 `validate_series_v2.py`로 확인한 원본 SHA·정책·보존 범위의 정합성도 S01·S02 완료본의 새 제작 검사와 구분한다.

S01의 완성 영상·Blender 프로젝트·기존 승인 참조와 과거 조형/리깅 승인 기록은 보존한다. V1.1 원본 12장면·138컷·21개 참여는 역사적 정본 기준이며, 현재 S03~S05의 확장 컷과 참여 및 음성 지시의 존재만으로 후속 영상 제작 완료를 주장하지 않는다.
