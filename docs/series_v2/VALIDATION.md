# V2 소스·정책 검증
`python3 scripts/validate_series_v2.py` 실행. Python 표준 라이브러리만 사용.
원본 2개 파일 실제 SHA-256, 12장면, 21개 원본 윤수 참여, 138컷 베이스라인, 제목/ID, S01 보호, S02~S12 각 ≥360초/10회 계획, 기존 20회 포함·신규 90회 일관성을 검사한다.

**이 테스트 PASS는 문서/정책 정합성 PASS에 한한다.** S02 상세 신규 대본의 사용자 승인이나 MP4 360초, 3D 움직임, 전체 참여 10회 작동, 실제 태블릿 검증은 아직 의미하지 않는다. 최종 영상은 `ffprobe`, 실제 플레이백, 립싱크/소품/관절/오디오 검증을 별도로 수행해야 한다.
