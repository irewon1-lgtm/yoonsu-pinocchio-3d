# 윤수 피노키오 3D — 시리즈 제작 기준 V2.0
**확정일:** 2026-11-23(KST) · **수정:** V2.1 — 사용자 요청에 따른 3~5화 오류 수정·문장별 음성 연기. 1·2화는 사용자 완료 선언에 따라 보존한다.

## 1. 잠금된 이야기 정본
- 전체는 **12편이 아닌 하나의 동화를 구성하는 12장면(S01~S12)**이다.
- 원본 `sources/01_STORY_MASTER_V1_1.md` 와 `sources/01_STEP2_PRODUCTION_STORYBOARD_SPEC.md`는 기존 **12장면, 21개 윤수 참여, 138컷, 358개 음성 대사/내레이션 배정**을 기록한 역사적 승인 정본이다.
- 이 두 원본을 수정/삭제/덮어쓰지 않는다. V2에서 신규 내용을 추가할 때는 `scenes/SXX/` 별도 파일을 생성하고 기존 사건, 대사, 등장인물, 핵심 교훈, 인과관계, 결말을 보존한다.
- 기존 138컷은 **베이스라인**이지 V2 확장 후 상한 컷 수가 아니다.

## 2. 이번 변경의 절대 조건
- **S01은 제작 완료된 기존 결과를 이번 계획에서 PASS/제외**: S01에 6분·참여 10회 기준 적용 금지. S01 영상, 소스, 기존 검사 로그를 수정/재생성/삭제하지 않는다.
- **S02~S12는 장면당 최소 360초(6분) 본편**. 윤수의 발화 대기/멈춤/반복 재생/메뉴/무의미한 정지 컷은 360초에 포함하지 않는다. 총 **최소 66분**의 S02~S12 서사.
- **S02~S12는 장면당 윤수 참여 총 10회**. 기존 S02~S12의 I02~I21 **20회는 110회에 포함**되어야 한다. 즉 신규 90회, 기존 20회, 합계 110회. 기존 I02 같은 ID를 재사용·변형하지 않고 새 ID는 `S02-P01` 등 장면 로컬로 관리한다.
- 기존 S08에는 참여가 0회였지만 새 V2 요청은 **S08에도 10회**다. 원본의 중요한 침묵/걱정/거짓말 망설임 장면은 참여 이벤트로 훼손하지 말고 다른 서사 지점에 배치한다.
- S12에서 실제 인간 모습으로 바뀌는 최종 캐릭터는 승인된 윤수 캐릭터 `CHAR_YOONSU_HUMAN`. 변신 순서·목각 시점·이후 인간형 유지 원본과 일치.

## 3. 길이 증가 방식
- 단순 반복·시간 끌기가 아니라 **인과관계를 가진 작은 사건, 인물 간 대화, 자연스러운 행동, 감정 변화, 소품 활용, 쇼트 전환**으로 장면별 살을 붙인다.
- 각 장면 시작 전 V1.1 원본 대사와 추가 V2 대사를 표기한 매핑표 작성. 원본 대사 순서와 의미를 바꾸지 않는다.
- 각 장면별 `SCRIPT_DRAFT → REVIEW_REQUIRED → APPROVED → ANIMATION → QA`. 신규 핵심 창작(대사/주요 장면 전개) 확정은 사용자 검토가 필요하다.
- 360초 입증은 상세 타임라인/음성 길이/편집본으로 검증하고, 최종 MP4는 `ffprobe`에서 실제 `duration >= 360`이어야 한다. 일부 길이는 인터랙션 이후 재생되더라도 정상 서사 경로에서 총 분량에 포함되어야 한다.

## 4. 윤수 교육 설계
- 윤수의 영어 문장 이해/발음 정확도를 전제로 하지 않는다. **화면 속 행동을 먼저 보여주고 짧은 영어를 연결하며 터치·따라 하기부터 시작**한다.
- 10개 참여는 각각 이야기에서 실제로 의미 있는 결과를 일으켜야 한다. 한 말을 열 번 반복시켜 개수만 채우지 않는다.
- **3~5화 초보자 기본 경로:** 질문 오디오 종료 → 본편 시계 정지 → 목표 세 단어 예시를 한 번 재생(마이크 OFF) → 예시 종료 뒤 발화 활동 또는 보호자 터치 → 반응 애니메이션 1회 → 후속 대사. 보호자 터치는 예시를 생략해 진행 가능. 입력 대기5초 뒤 다시 듣기·터치를 제시한다. 예시·재시도는 본편 시간에 포함하지 않는다. 1·2화 완료본은 이 변경으로 재제작하지 않는다.
- 단어 내용 인식(STT)이나 발음 점수화 금지. 재시도 중 오탐/중복 트리거 방지. 보호자 터치로도 스토리 완주 가능하게 설계.

## 5. 3D 시네마틱 제작 기준
- S01에서 승인/고정된 스타일·실제 리그/음성/재질/작업환경을 우선 조사·재사용한다. 새 주요 캐릭터 디자인·성우 변화는 사용자 승인.
- 인물이 스스로 눈/표정/시선/손짓/체중 이동/걸음/물체 접촉/반응을 한다. 카메라 줌, 스프라이트 흔들기, 정지 이미지 배열로 3D 완성을 주장하지 않는다.
- 관절 분리, 다리/팔 뒤집힘, 소품 위치 순간이동, 발 접지 미흡, 심각한 관통, 배경-캐릭터 크기 붕괴, 표정/목소리 혼용은 FAIL.
- 고비용 렌더·유료 GPU·무단 업로드 금지. 오픈소스/무료 도구 사용 시 라이선스 기록. 과도한 반복 테스트 없이 게이트를 구분한다.

## 6. 단계별 PASS 조건
| 단계 | 요구 산출물 | 완료 판정 |
|---|---|---|
| G0 소스 | 정본 SHA, 원본 맵, S01 참조 자산 현황 | 존재/해시/정합성 확인 |
| G1 각본 | 장면 6분+ 상세 대본, 원본 1:1 보존, 참여 10회, 사건별 시간표 | 주요 창작 사용자 검토/승인 전 REVIEW_REQUIRED |
| G2 콘티 | 신규 전체 컷, 구도/인물/소품/대사/WAIT→REACT 매핑 | 연출·대사·카메라의 인과관계 PASS |
| G3 동작 | 난도 높은 동작 리그·영상 증거, 표정/접지/소품 접촉 | 실제 3D 프레임에서 품질 판정 |
| G4 제작 | 캐릭터별 음성·효과·립싱크·완성 타임라인·편집소스 | 재생·타이밍·연기 시험 |
| G5 QA | MP4, ffprobe, 전체 오디오/자막/QA, 10개 이벤트, 라이선스·해시 | 360초 이상 + 서사/기술 PASS |
| G6 인계 | MP4, 프로젝트, QA·SHA·차이/승인 이력 | 파일 링크와 미확인 명시 |

**검증의 정직성:** 이 기준 문서를 GitHub에 올리는 것은 영상 제작 완료를 뜻하지 않는다. `PASS/FAIL/NOT_RUN/REVIEW_REQUIRED/BLOCKED_RESOURCE`를 실제 증거 기준으로 기록한다.

## 7. 변경 승인 범위
- **사전 승인:** 원본 대사/핵심 사건 변경, 새 주요 외형/성우, 교육 방법 전환, S01 변경, 신규 장면 상세 각본 최종 확정.
- **자동 진행:** 기존 결정 범위의 코드·아트 파일 분리 제작, 자동 테스트, 오류수정, 회귀 검수, SHA 관리, 별도 브랜치 커밋/푸시.
- **현재 작업 대상은 S03~S05 수정 및 음성 연기 지시다. S01·S02는 사용자 완료 선언을 유지하고 재검토·재합성하지 않는다.** 이번 요청은 수정과 연기 지시 작성을 승인한 것이며, 실제 합성 음원의 청취 승인·새 성우 확정·영상 완성을 대신하지 않는다.
- 모든 신규 음성 제작은 `VOICE_PERFORMANCE_BIBLE_V2_1.json`, 각 줄의 `voice_direction`, `CODEX_VOICE_ACTING_HANDOFF.md`를 따른다. 참조음원+text만 넣어 문장별 연기 지시를 버리는 옛 3·4화 합성 경로는 사용하지 않는다.
