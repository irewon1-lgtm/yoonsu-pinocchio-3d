## 대사마다 추가한 제작 정보

각 줄은 고유 ID와 정확한 영어 대사, 고정 캐릭터 프로필, 듣는 상대, 말하는 목적, 감정, 한국어 연기 지시, 영어 합성 지시, 계획 속도·에너지·강조 단어, 전후·문장 내부 쉼, 피할 말투를 가진다. 앞뒤 대사는 문맥 입력으로 별도 보관한다. **`spoken_text`만 발화하며 연기 설명·태그·캐릭터 이름·앞뒤 문맥은 읽지 않는다.**

예를 들어 S03-U002 “School?”은 처음 들은 말의 뜻을 되묻는 짧은 반응이며, 작은 상승조만 사용한다. S03-U015 “You're still learning.”은 제페토가 서툰 손자를 느긋하게 받아들이는 말이다. S03-U020의 학교·귀가 약속은 낮은 음량에서도 핵심이 들리도록 뜻 단위로 나누고 따뜻한 무게를 둔다. S05-U015의 귀뚜라미는 약속을 생각나게 하되 혼내지 않는다.

모든 줄을 같은 음높이·같은 말끝·같은 긴 쉼으로 읽는 방식은 지시에 부합하지 않는다. 참조 음원은 화자를 고정하기 위한 것이며 한 문장의 억양을 전체에 복제하는 용도가 아니다.

## Codex 연결에서 바뀐 점

기존 S03/S04 호출에서는 `text`와 `audio_prompt_path`만 전달했고 문장별 연기 지시 전달 코드가 없었다. 이 상태는 평평한 낭독을 반복할 수 있으므로 기존 `--synthesize` 경로는 `DIRECTED_ADAPTER_REQUIRED`를 반환하게 했다. 기본 참조 검사와 `--export-jobs PATH` 내보내기는 계속 가능하다.

새 `voice_direction_plan.json`에는 캐릭터 기준과 해당 줄의 영어 연기 지시를 결합한 `instruct_prompt_en`이 있다. Codex는 실제 설치 엔진이 지원하는 기능을 확인하고 이 지시·속도·쉼을 전달하는 연결을 구현해야 한다. 현재 엔진의 지원 기능을 확인하지 않고 가상의 인수나 SSML을 넣지 않는다. 자연어 연기 입력을 지원하지 않는 엔진에서는 실제 지원 제어와 승인 화자 참조를 사용할 수 있는지 먼저 확인한다.

한 문장의 전후 쉼을 합성 음원과 편집에서 중복 적용하지 않도록 처리 규칙도 제공했다. 대표 문장으로 화자 정체성·감정 차이·대화성을 확인한 뒤 전체를 생성하고, 줄별 실제 오디오와 청취 결과를 남긴다.

마지막 문서 동기화에서 S05 한 컷의 설명에 남은 과거 432초 문구를 현재 계획을 참조하는 표현으로 고쳤다. 대사·연기·시간 값은 바뀌지 않았다. S05 대본·작업표·CSV를 다시 생성한 뒤 해당 화의 지시 검증과 참조 검사·내보내기를 재실행했고 두 항목 모두 종료 코드 0이었다. 이 추가 실행도 증거에 포함했다.

초기 검사에서는 새 검사기에 복사한 스토리보드 SHA 문자열 오타와 작성 중 S03의 `clock` 필드 누락이 발견됐다. 원본을 수정하지 않고 검사기 상수 및 해당 데이터 필드만 최소 수정한 뒤 같은 검사를 다시 실행했다. 실제 시범이 C02에 있는 항목을 C03으로 강제하던 새 검사기의 가정도 실제 시범 위치와 질문 전 순서를 확인하도록 바로잡았다. 초기 실패와 재검증 결과는 증거 JSON에 함께 보관한다.

**미실행:** 실제 합성, 엔진 연기 전달, 청취 승인, 립싱크, 새 영상 렌더, 기기 입력 전체 동작. CI와 원격 게시 여부는 게시 후 확인 결과를 따르며 이 로컬 보고서는 아직 실행하지 않은 CI를 성공으로 표시하지 않는다.
