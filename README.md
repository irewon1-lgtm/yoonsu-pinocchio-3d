# yoonsu-pinocchio-3d

## 제작 원본 및 Codex 작업 시작 위치

**실제 작업 브랜치:** [s01/full-story-production](https://github.com/irewon1-lgtm/yoonsu-pinocchio-3d/tree/s01/full-story-production)

현재 main은 최소 안내 브랜치입니다. S01 완성 영상과 Blender 소스, 12장면 전체 대본 V1.1·138컷 스토리보드, S02~S12 제작 규칙 V2.0은 위 제작 브랜치에 있습니다.

**Codex 시작 절차**
1. `git fetch origin && git switch s01/full-story-production`
2. 제작 브랜치의 [AGENTS.md](https://github.com/irewon1-lgtm/yoonsu-pinocchio-3d/blob/s01/full-story-production/AGENTS.md)를 읽습니다.
3. [CODEX_HANDOFF.md](https://github.com/irewon1-lgtm/yoonsu-pinocchio-3d/blob/s01/full-story-production/docs/series_v2/CODEX_HANDOFF.md)를 따릅니다.
4. `python3 scripts/validate_series_v2.py` 실행 후 S02 G0/G1부터 진행합니다.

**확정 정책:** S01은 재작업하지 않습니다. S02~S12는 기존 V1.1 원본을 유지하면서 장면마다 실제 본편 6분 이상, 윤수 참여 총 10회(기존 참여 포함)로 확장합니다. 상세 신규 대본은 사용자 검토 후 확정합니다.
