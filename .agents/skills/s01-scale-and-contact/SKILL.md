# Real-world and screen-space scale gate

1. 현재 원본 배경과 카메라를 고정하며 월드 크기 기준을 정한다. 제페토/피노키오/요정의 **root translation만이 아닌 메쉬 실제 bounding box**와 Blender units를 계산한다.
2. 다음은 **초기 시안의 상대비 예시**로만 사용한다. 원화·장면에서 더 맞는 크기가 있다면 실측 관계를 설명하고 조정한다: 제페토 키/피노키오 키 대략 1.5~1.9, 요정 몸높이/피노키오 키 0.3~0.6, 요정 날개 포함 너비/창문 개구부 너비 0.7 이내. 절대값이 아니라 승인 전 화면상 지침이며 시안 비교로 확정.
3. 작업대 상판은 성인 제페토의 자연스러운 허리~배꼽 높이에 위치하게 한다. 피노키오 C06 누운 상태는 상판/천 받침에 머리·등·다리 접촉, C07 끝은 두 발 접촉 및 작업대 상판 경계 여유 확인.
4. 창틀/커튼 깊이와 요정의 날개까지 포함한 통과 볼륨을 검사하되, 최종 카메라에서 **픽셀 실루엣**이 차지하는 공간도 함께 검사한다.
5. 카메라만 변경해 비율 오류를 숨기지 않는다. 메인/진단 카메라 2종과 사람 눈높이의 광각 렌더를 비교하고 원근 차이에 의한 오해를 보고한다.
6. 접촉 프록시는 collision/diagnostic 컬렉션으로 유지하고, 최종 렌더용 실제 시각 재질 또는 원화와 맞는 가림/매트를 별도로 둔다.
7. 대상 대사·이야기 연속성: C06 정지 → C07 기상 종료 → C08 이어지는 위치까지 기준을 동일한 월드 좌표로 기록한다. 실제 동작/접촉 모션은 D2/D3 전까지 NOT_RUN.
8. JSON으로 모델 bbox, 축별 높이, 테이블 top Z, 화면 bbox, 클리핑/가림 여부를 저장. 사용자 비교 보드 제출.
